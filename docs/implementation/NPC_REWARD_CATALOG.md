# NPC 획득 보상 통합 원장

> 설계 상태: 1세대 테스트 월드 기준 정리 / 핵심 진행 요소 데이터 반영 중
>
> 대상: 현재 시스템에서 실제 지급할 수 있는 소모품, 낚싯대, 기술머신, 중요한 물건과 비전머신 권한

## 1 범위와 관리 규칙

월드에 배치할 아이템 지급 NPC와 주요 해금 NPC를 이 문서 하나에서 관리한다. 콘텐츠 원본,
CVES 이벤트, Easy NPC 프리셋과 월드 배치는 이 원장을 기준으로 작성한다.

포함:

- 연구소, 포켓몬센터, 마을과 길목에서 한 번 지급하는 잡다한 소모품
- 현재 Cobblemon에서 사용할 수 있는 낚싯대 3종
- 지역의 트레이너나 전문가가 한 번 지급하는 기술머신
- 지도, 도감, 포켓내비, 포켓파인더와 동전케이스처럼 현재 실제 사용하는 중요한 물건
- 1세대 테스트 월드의 지형 관문에 실제로 사용하는 비전머신
- 배지 진행을 검사하는 핵심 관문 NPC

제외:

- 아직 대응 시스템이 없는 자전거와 가르침TV 같은 아이템
- 실프주식회사, 승선티켓처럼 특정 1세대 스토리 구현을 전제로 하는 보상
- 상점 반복 판매, 야생 포켓몬 드롭, 상자와 일반 필드 아이템
- 언젠가 쓸 수 있다는 이유만으로 미리 등록하는 후보 아이템

공통 규칙:

- 같은 보상은 고유 `보상 ID` 하나로 추적하고 플레이어당 한 번만 지급한다.
- 인벤토리가 가득 차면 완료 처리하지 않고 다음 대화에서 남은 수량을 다시 지급한다.
- NPC 원본, 프리셋과 실제 월드 배치를 모두 확인해야 `획득 가능`으로 표시한다.
- 기능 이름을 붙인 지원원 대신 장소에 어울리는 포켓몬 NPC 역할을 사용한다.
- 한 NPC에게 여러 보상을 몰지 않고 탐험 동선에 분산한다.
- 구현 상태는 `기획`, `데이터`, `프리셋`, `배치`, `획득 가능` 중 하나로 기록한다.

- 무료 지급 이후의 반복 수급은 상점과 경제 시스템이 담당한다.

## 3 낚싯대 지급 NPC

Cobblemon의 실제 낚싯대 3종을 사용한다. Adventure의 낚시 풀 판정도 각 등급에 연결되어
있다.

| 보상 ID | 등급 | NPC 콘셉트 | 권장 배치 | 지급 아이템 | 적용 낚시 풀 | 상태 |
|---------|------|------------|-----------|-------------|---------------|------|
| `fishing/poke_rod` | 초반 | 마을 낚시꾼 | 첫 강·호수 마을 | `cobblemon:poke_rod` | `old_rod` | 기획 |
| `fishing/great_rod` | 중반 | 숙련 낚시꾼 | 큰 호수·해안 정착지 | `cobblemon:great_rod` | `good_rod` | 기획 |
| `fishing/ultra_rod` | 후반 | 낚시의 달인 | 외해·후반 수역 입구 | `cobblemon:ultra_rod` | `super_rod` | 기획 |

- 세 낚싯대는 서로 다른 정착지에 배치한다.
- 다음 등급은 이전 낚싯대 보유와 지역 진행을 함께 확인한다.
- 특수 볼 테마와 고대 낚싯대는 기본 진행 보상에서 제외한다.

- 가챠와 상점은 반복 수급, 이 NPC들은 최초 발견 보상을 담당한다.

### 5.1 오박사의 포켓몬 도감

스타팅 포켓몬을 고른 직후 오박사는 포켓몬 도감만 지급한다. 도감은 만난 포켓몬과 포획한
포켓몬을 기록하는 오박사의 연구 도구로 설명한다.

대사 방향:

> 이건 포켓몬 도감이란다. 만난 포켓몬의 정보가 자동으로 기록되지. 여러 포켓몬을 만나
> 도감을 완성해 보렴.

### 5.2 태초마을의 첫 출발 장비

첫 파트너를 받은 플레이어가 태초마을 북쪽 관문을 처음 통과하려 하면 문지기 민호가 오박사에게
맡아 둔 포켓내비를 건넨다. 포켓내비 수령 플래그까지 기록되어야 관문이 열리므로 지급 대화를
건너뛰고 마을을 나갈 수 없다. 파트너가 없다면 먼저 연구소에 다녀오라고 안내한다.

### 5.3 상록시티의 여행 안내 세트

플레이어가 상록시티에 처음 도착하면 같은 NPC가 마을지도와 포켓파인더를 함께 지급한다.
마을지도는 마을과 길을 확인하는 광역 안내를, 포켓파인더는 현재 장소에서 관장, 주요 NPC와
다음 목표를 찾는 근거리 안내를 담당한다.

포켓파인더는 일반 미니맵을 대체하지 않는다. 지형과 건물 내부 구조를 항상 노출하지 않고,
제한된 범위 안에서 다음 대상만 신호로 표시한다.

- 체육관 관장과 아직 상대하지 않은 트레이너
- 진행에 필요한 주요 NPC
- 보상이나 퀘스트를 가진 NPC
- 현재 추적 중인 다음 목표
- 기존 CobbleNav가 탐지하는 주변 포켓몬

지도 제작자 NPC는 사용하지 않는다. 상록시티 서쪽 관문 안내원이 지도와 포켓파인더를 지급해
플레이어가 주요 시설과 다음 동선을 익히게 하고, 재대화 시 석영고원 관문의 조건을 안내한다.

### 5.4 이수재의 이동형 PC

25번도로 끝의 집에 있는 이수재가 PC와 포켓몬 박스를 설명한 뒤 플레이어를 포켓몬 전송망에
등록한다. 등록이 끝나면 플레이어 메뉴에서 장소와 관계없이 PC를 열 수 있다. 화면과 기존 코드의
기능명은 `원격 PC`를 유지하되 콘텐츠에서는 가지고 다니며 쓰는 `이동형 PC`로 설명한다.

- NPC ID: `cobbleventure:npc/rewards/feature_pc_technician`
- 이벤트: `cobbleventure:event_script/rewards/feature_pc_technician`
- 해금 기능: `pc`
- 완료 플래그: `cobbleventure:flag/rewards/feature/pc`
- 지급 방식: 최초 안내 대화에서 영구 기능 해금
- 재대화: 이미 전송망에 등록됐다는 안내만 출력
- 상태: NPC 원본, CVES 이벤트, 바인딩과 Easy NPC 프리셋 구현 완료

### 5.5 중요한 도구 보호와 복구

도감, 포켓내비, 포켓파인더와 동전케이스는 `important-items.json`에서 통합 관리한다. 각 도구는
별도의 획득 플래그를 기록하며, 획득 후에는 가방에서 버리기·삭제·판매하거나 바닐라 드롭 키로
버릴 수 없다. 사망 시에도 드롭되지 않으며, 획득 플래그가 참인데 일반 인벤토리와 확장 가방에
아이템이 없으면 서버가 자동으로 한 개를 복구한다.

지도, 이동형 PC와 비전머신처럼 아이템이 아닌 영구 기능은 기존 플레이어 권한 자체가 소유
기록이므로 아이템 복구 대상에 포함하지 않는다.

## 6 테스트용 1세대 월드 비전머신

현재 1세대 월드는 전체 세대 콘텐츠가 아니라 진행 구조를 검증하는 테스트 월드다. 실제 지형
관문과 후반 이동에 사용하는 플래시, 파도타기, 락클라임과 공중날기만 진행 보상으로 사용한다.
비전머신은 소비 아이템이 아니라 플레이어별로 저장되는 영구 권한 플래그다.

| 순서 | 보상 ID | 비전머신 | 진행 목적 | 획득 시점·지급 방식 | 월드 설계 | 상태 |
|------|---------|----------|-----------|---------------------|-----------|------|
| 1 | `field_move/flash` | 플래시 | 보라시티 방면 어두운 동굴 통과 | 갈색시티 클리어 후 개방되는 블루시티 옆 발전소 던전 클리어 보상 | 미보유 시 동굴 탐색 제한 | 획득 가능 |
| 2 | `field_move/surf` | 파도타기 | 바다를 건너 홍련섬 진입 | 연분홍시티 관장 격파 보상 | 홍련섬은 파도타기로만 정상 접근 | 획득 가능 |
| 3 | `field_move/rock_climb` | 락클라임 | 실제 고지대인 석영고원 진입 | 상록시티 체육관에서 비주기 격파 및 그린배지 획득 보상 | 석영고원은 락클라임으로만 정상 접근 | 획득 가능 |
| 4 | `field_move/fly` | 공중날기 | 석영고원 도착 후 이전 지역 왕복과 비행 탐험 | 석영고원 최초 도착 보상 | 석영고원 진입 조건으로 사용하지 않음 | 도착 길목 NPC로 획득 가능 |

진행 순서는 `플래시 → 파도타기 → 락클라임 → 석영고원 도착 → 공중날기`로 고정한다.
석영고원 진입 시에는 락클라임 권한을 서버에서 검사한다. 공중날기는 석영고원에 정상적으로
도착한 뒤 지급하므로 석영고원 진입 관문을 대신하지 않는다.

### 6.1 플래시 확정 흐름

```text
갈색시티 클리어
  → 블루시티 옆 발전소 개방
  → 발전소 던전 클리어
  → 플래시 획득
  → 보라시티 방면 어두운 동굴 통과
```

발전소 월드 오브젝트, 던전 완료 플래그와 첫 클리어 플래시 보상은 구현되어 있다. 갈색시티의
오렌지배지를 보유하지 않은 플레이어는 발전소 던전에 입장할 수 없다.

### 6.2 석영고원 확정 흐름

```text
상록시티 체육관에서 비주기 격파
  → 그린배지와 락클라임 영구 권한 획득
  → 고지대 통로에서 락클라임 권한 검사
  → 석영고원 최초 도착
  → 공중날기 영구 권한 획득
```

월드 데이터의 석영고원 고지대 접근 조건인 `cobbleventure:field_move/rock_climb`은 유지한다.
공중날기 보상은 최초 도착 이벤트에서 플레이어당 한 번만 지급한다.

### 6.3 이번 월드에서 사용하지 않는 비전머신

| 비전머신 | 처리 |
|----------|------|
| 괴력 | 대응 바위 퍼즐이 없으므로 미배치 |
| 바위깨기 | 대응 진행 관문이 없으므로 미배치 |
| 안개제거 | 대응 안개 지역이 없으므로 미배치 |
| 바다회오리 | 대응 소용돌이 수역이 없으므로 미배치 |

NPC 원본과 권한 구현은 다른 세대 월드에서 재사용할 수 있도록 남기되 테스트 월드에는
배치하지 않는다.

### 6.4 순간이동 확정 흐름

순간이동은 지역 관문용 3종과 분리된 공통 편의 기능이다. 달맞이산을 건너 블루시티에 처음
도착한 뒤 획득한다. 긴 길을 건너왔으니 집이나 이미 방문한 마을로 돌아가고 싶을 때
사용하라는 안내와 함께 지급한다.

- 획득 시점: 달맞이산 통과 후 블루시티 첫 도착
- 지급 NPC: 달맞이산 동쪽에서 블루시티로 들어오는 길의 초능력자
- 기능: 지도에서 방문한 마을 중 원하는 목적지 선택
- 진행 영향: 필수 지역 관문에는 사용하지 않으며 잠긴 마을로 이동할 수 없음
- 대사 방향: "먼 길을 건너왔으니 집으로 돌아가고 싶을 때 순간이동을 사용해 봐."
- 호환: `settlement_teleport`는 저장 마이그레이션 전까지 내부 키로 유지

## 7 노랑시티 4방향 관문

노랑시티는 남쪽, 동쪽, 서쪽과 북쪽의 네 관문을 통해서만 정상 진입할 수 있다. 각 관문에
본가식 검문 NPC를 한 명씩 배치하고, 지정된 6개 배지를 모두 획득한 플레이어만 통과시킨다.

| 방향 | 월드 오브젝트 ID | NPC | 상태 |
|------|-------------------|-----|------|
| 남쪽 | `saffron_gate_south` | 노랑시티 관문 경비원 | 획득 조건·NPC 반영 완료 |
| 동쪽 | `saffron_gate_east` | 노랑시티 관문 경비원 | 획득 조건·NPC 반영 완료 |
| 서쪽 | `saffron_gate_west` | 노랑시티 관문 경비원 | 획득 조건·NPC 반영 완료 |
| 북쪽 | `saffron_gate_north` | 노랑시티 관문 경비원 | 획득 조건·NPC 반영 완료 |

### 7.1 통과에 필요한 배지

단순히 배지 수가 6개 이상인지 검사하지 않고 다음 6개 배지를 각각 보유했는지 검사한다.

| 배지 | 배지 ID | 획득 지역 |
|------|---------|-----------|
| 회색배지 | `cobbleventure:badge/kanto/boulder` | 회색시티 |
| 블루배지 | `cobbleventure:badge/kanto/cascade` | 블루시티 |
| 오렌지배지 | `cobbleventure:badge/kanto/thunder` | 갈색시티 |
| 무지개배지 | `cobbleventure:badge/kanto/rainbow` | 무지개시티 |
| 핑크배지 | `cobbleventure:badge/kanto/soul` | 연분홍시티 |
| 그린배지 | `cobbleventure:badge/kanto/earth` | 상록시티 |

다음 배지는 노랑시티 진입 조건에서 제외한다.

- 노랑시티 골드배지: `cobbleventure:badge/kanto/marsh`
- 홍련섬 크림슨배지: `cobbleventure:badge/kanto/volcano`

따라서 노랑시티와 홍련섬을 제외한 여섯 체육관을 먼저 완료해야 노랑시티에 진입할 수 있다.

### 7.2 관문 동작

```text
관문 접근
  → 플레이어별 지정 6배지 보유 검사
  → 하나라도 없으면 검문 NPC가 통행 거부
  → 부족한 배지 목록 안내
  → 6개를 모두 보유하면 해당 플레이어 통과 허용
```

- 네 관문은 같은 조건과 대화 이벤트를 공유한다.
- 각 관문에는 같은 검문 NPC 프리셋을 한 명씩 배치한다.
- `condition_mode`는 `all`을 사용하고 여섯 `badge` 조건을 선언한다.
- 문이 열렸다는 전역 상태가 아니라 플레이어별 배지 상태로 통과를 판정한다.
- 멀티플레이에서 다른 플레이어가 연 문을 따라 들어가는 우회를 허용하지 않는다.
- 비행, 순간이동과 다른 모드 이동으로 관문을 우회해도 노랑시티 경계에서 같은 조건을 다시
  검사하고 마지막 허용 체크포인트로 돌려보낸다.
- 거부 대사는 아직 도전하지 않은 체육관을 찾아가라는 방향으로 작성하고, 실제 부족한 배지
  목록을 함께 보여 준다.

`generation_1.json`의 네 관문은 여섯 `badge` 조건과 공통 경비원 프리셋을 사용한다.
통과 판정은 `condition_mode: all`로 플레이어마다 수행된다.

## 8 상록시티 서쪽 석영고원 관문

상록시티 서쪽 관문은 석영고원 방면의 후반 관문이다. 관문 안내원이 지도와 포켓파인더 지급을
담당하면서, 통과 시점에는 관동 체육관의 여덟 배지를 모두 보유했는지 플레이어별로 검사한다.

- 월드 오브젝트 ID: `viridian_gate`
- NPC: `cobbleventure:npc/rewards/feature_map_guide`
- 통과 조건: 회색·블루·오렌지·무지개·핑크·골드·크림슨·그린배지
- 판정 방식: `condition_mode: all`과 8개의 개별 `badge` 조건
- 역할 분리: 8배지 검사는 관문 통과 조건이고, 락클라임은 이후 석영고원 고지대 통로 조건이다.
- 상태: 배지 조건과 NPC 배치 반영 완료

## 10 데이터 반영 절차

1. 이 원장에서 배치할 보상과 NPC 콘셉트를 먼저 확정한다.
2. 실제 아이템 ID와 현재 모드에서의 사용 가능 여부를 확인한다.
3. NPC 원본과 CVES 최초 지급 이벤트를 작성한다.

7. 검증 결과를 원장의 상태에 반영한다.
