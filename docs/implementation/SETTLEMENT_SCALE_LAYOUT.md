# 마을 규모와 배치 계획

## 목적

현재 테스트 마을보다 큰 마을을 안정적으로 배치하고, 건물 수를 늘려도 도로·시설·NPC 공간이 서로 충돌하지 않게 한다.

- 관련 기능: `SETTLEMENT-LAYOUT-01`
- 결정: `DEC-WORLD-017` — 마을 크기는 프리셋과 명시적 제한값을 함께 사용한다.
- 상태: 구현 예정

## 크기 프리셋

| 크기 | 권장 내부 범위 | 건물 부지 | 트레이너 예산 | 용도 |
|---|---:|---:|---:|---|
| `small` | 192×192 | 8~12 | 6~10 | 소도시·휴게 마을 |
| `medium` | 256×256 | 14~20 | 10~16 | 일반 체육관 도시 |
| `large` | 384×320 이상 | 22~32 | 16~24 | 시작 도시·주요 도시 |

시작 마을은 `large`를 사용한다. 실제 범위는 청크 경계에 맞춰 반올림하고, 마을 바깥에 최소 64블록의 주변 바이옴 완충 지대를 둔다.

## 마을 JSON 확장 초안

```json
{
  "layout_profile": {
    "size": "large",
    "planner": "cobbleventure:layout/radial_grid",
    "road_width": 7,
    "minimum_lots": 22,
    "maximum_lots": 32,
    "building_spacing": 5,
    "plaza_radius": 18
  },
  "building_kit": "cobbleventure:building_kit/starter_plains"
}
```

## 배치 단계

1. 마을 경계와 중심 광장 앵커를 확정한다.
2. 관문에서 광장까지 반드시 연결되는 주도로를 만든다.
3. 포켓몬센터·상점·체육관 등 필수 시설 부지를 먼저 예약한다.
4. 보조 도로와 주택 부지를 배치한다.
5. NPC 구역, 장식, 빈터와 안전 여백을 채운다.
6. 모든 출입구에서 도로까지 보행 경로가 있는지 검증한다.

초기 플래너는 결정적인 `radial_grid` 하나로 시작한다. 무작위 jigsaw 확장만으로 마을 크기를 결정하지 않는다.

## 시작 마을 기준

- 마을 내부: 최소 384×320블록
- 주변 바이옴 완충 지대: 각 방향 최소 64블록
- 경계 띠: 16블록 이상
- 필수 시설: 체육관, 포켓몬센터, 상점, 광장
- 주택: 최소 12동
- NPC용 구역: 광장, 주거, 체육관 앞, 관문, 공원
- 모든 생성 대상 청크는 플레이어 이동 전에 준비

현재 `starter_town.json`의 과거 좌표와 테스트 부트스트랩 좌표는 위 기준에 맞춘 단일 좌표계로 다시 작성한다.

## 검증 항목

- 부지와 마을·벽 경계의 교차 검사
- 건물끼리 충돌 및 도로 침범 검사
- 필수 시설 정확히 1개 존재 검사
- 관문에서 광장·센터·체육관까지 경로 탐색
- 플레이어 시작점의 머리 공간과 낙하 안전 검사
- 준비 청크 수와 생성 시간 기록

## 완료 기준

- 시작 마을이 `large` 기준을 만족하고 기존보다 넓다.
- 필수 시설과 최소 부지 수가 항상 보장된다.
- 생성 실패 시 부분 완성 상태로 입장시키지 않고 실패 원인을 로그와 상태 데이터에 남긴다.
- 마을 규모 변경은 JSON과 키트 데이터만으로 가능하다.
