# 1세대 시작 지역 구현 체크리스트

이 문서는 시작 지역의 바이옴, 마을, 경계 벽, 건축물, 안전 기반층과 트레이너 준비 작업을 한곳에서 추적하는 실행용 체크리스트다. 설계 근거와 상세 데이터 형식은 [1세대 시작 지역 통합 구현 계획](GENERATION_ONE_BATCH_IMPLEMENTATION.md) 및 연결된 세부 문서를 따른다.

## 사용 규칙

- 항목이 실제 코드·데이터·게임 테스트까지 끝났을 때만 `[x]`로 변경한다.
- 부분 구현은 체크하지 않고 바로 아래에 진행 상황과 남은 작업을 적는다.
- 생성 결과가 바뀌는 작업은 새 테스트 월드로 검증한다.
- 각 단계의 완료 조건을 만족한 뒤 다음 단계로 넘어간다.
- 실제 트레이너 NPC 스폰은 이 체크리스트의 후속 단계이며, 선행 조건이 모두 끝나기 전에는 활성화하지 않는다.

- [ ] 현재 정상 작동하는 CurseForge 개발 ZIP의 파일명과 SHA-256 기록
- [ ] 현재 시작 차원의 생성 버전 기록
- [ ] 현재 플레이어 시작점, 마을 중심, 체육관 입구 좌표 기록
- [ ] 현재 표면 높이와 지형 수직 단면 기록
- [ ] 현재 시작 마을 구조물과 필수 시설 목록 기록
- [ ] 변경 전 새 월드 생성과 첫 진입 절차 재현
- [ ] 생성 결과 비교용 스크린샷과 로그 보관

완료 조건: 변경 전 빌드를 언제든 다시 임포트하고 같은 테스트를 재현할 수 있다.
