## 작성 원칙

- 요구사항의 기준은 [프로젝트 기획서](../PROJECT_PLAN.md)로 유지한다.
- 각 구현 문서는 관련 기능 ID와 결정 ID를 명시한다.
- 확정된 결정, 현재 권고안, 검증이 필요한 가정을 구분한다.
- 게임, 모드 로더와 의존 모드 버전을 문서 상단에 기록한다.
- 외부 구조물과 데이터팩을 참고할 때 출처와 라이선스를 함께 기록한다.
- 구현 전에 실험 방법과 합격 기준을 정의하고 결과를 남긴다.

## 권장 작업 순서

1. 월드 생성 문서에서 체육관 도시 한 개의 배치와 복구 방식을 검증한다.
2. 진행 문서에서 해당 도시의 관장 승리와 지방 해금 상태를 연결한다.
3. 트레이너, 경제와 보상 데이터를 수직 구간에 추가한다.
4. 운영 및 복구 절차가 닫힌 뒤 챔피언 시스템과 추가 지방을 확장한다.
