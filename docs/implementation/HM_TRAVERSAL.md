# 비전머신과 포켓몬 탑승 이동

> 관련 요구사항: F-01, F-07, F-12
>
> 관련 결정: D-16 비전머신 기반 탑승, D-17 공중날기 지역 경계 예외, D-18 파도타기 수중 규칙
>
> 적용 아키텍처: 3안 보호형 하이브리드
>
> 설계 상태: 플레이어 해금 기반 탑승 차단 프로토타입 구현 / 포켓몬 개체 적용 단계 미구현

## 1 목적

Cobblemon의 조건 없는 포켓몬 탑승을 포켓몬 본가식 비전머신 진행과 연결한다. 플레이어가 비전머신을 획득하고 적합한 포켓몬에게 이동 능력을 적용해야 공중날기와 파도타기 탑승을 사용할 수 있다.

```text
비전머신 획득
  → 플레이어 사용 권한 해금
  → 적합한 포켓몬에게 능력 적용
  → 해당 포켓몬 탑승
  → 지역 이동 규칙 변경
```

비전머신은 단순 이동 편의가 아니라 세대 월드 탐험 방식 자체를 바꾸는 진행 보상이다.

## 2 탑승 권한 모델

포켓몬이 Cobblemon에서 탑승 가능한 종이라는 사실만으로 탑승을 허용하지 않는다. 서버는 탑승 시작 시 다음 조건을 검사한다.

| 검사 | 설명 |
|------|------|
| 플레이어 해금 | 플레이어가 해당 비전머신 사용 자격을 획득했는가? |
| 포켓몬 적성 | 종·폼 데이터가 해당 이동 방식에 적합한가? |
| 포켓몬 적용 | 그 개체에 비전머신 이동 능력이 적용되어 있는가? |
| 현재 공간 | 세대 월드, 서바이벌 월드, 던전과 리그가 해당 이동을 허용하는가? |
| 상태 검사 | 전투, 기절, 탑승 금지 구역 또는 재사용 대기시간 상태가 아닌가? |

초기 이동 유형은 다음처럼 구분한다.

| 이동 유형 | 요구 능력 | 역할 |
|-----------|-----------|------|
| `LAND` | 프로젝트 전용 지상 탑승 능력·장비(명칭 미정) | 지상 이동 가속 |
| `SURF` | 파도타기 | 깊은 물 횡단과 수상 탐험 |
| `FLY` | 공중날기 | 절벽·산맥·지역 경계 자유 횡단 |

모든 탑승 유형은 대응하는 이동 권한을 요구한다. 지상 탑승에 사용할 비전머신·탑승 장비의 이름과 획득처는 이후 결정하고, 파도타기와 공중날기는 해당 비전머신 진행에 직접 연결한다.

## 3 데이터 구조 초안

종과 폼별 이동 적성은 코드에 직접 넣지 않고 데이터로 관리한다.

```json
{
  "species": "cobblemon:charizard",
  "form": "normal",
  "ride_capabilities": {
    "land": true,
    "surf": false,
    "fly": {
      "enabled": true,
      "max_y": 192,
      "ascent_speed": 0.8,
      "cruise_speed": 1.0
    }
  }
}
```

`max_y` 값은 예시이며 밸런스 테스트 전에는 확정하지 않는다.

플레이어와 포켓몬 개체에는 다음 상태가 필요하다.

```text
PlayerTraversalState
  unlocked_hms
  badge_requirements
  tutorial_flags

PokemonTraversalState
  learned_traversal_hms
  traversal_cooldowns
```

포켓몬 진화·폼 변경 시 현재 능력을 유지할지 새 폼 적성을 다시 검사할지 정책이 필요하다. 기본안은 비전머신 습득 기록은 유지하되 현재 폼이 지원하지 않는 이동은 일시적으로 사용하지 못하게 하는 것이다.

## 4 공중날기

### 4.1 지역 경계 예외

공중날기가 적용된 비행 포켓몬에 정상 탑승한 플레이어는 세대 월드의 지역 경계를 관문과 배지 조건 없이 넘어갈 수 있다.

```text
지역 경계 진입
  → 정상 FLY 탑승 확인
  → 포켓몬의 공중날기 적용 여부 확인
  → 세대 월드가 비행 허용 상태인지 확인
  → 통과 허용
```

이 예외는 **물리적 탐험 범위**만 넓힌다. 선행 관장을 이기지 않았다면 다음 지역의 체육관 도전, 진행 퀘스트, 상점 재고, 리그 포탈과 다음 세대 해금은 계속 잠겨 있다.

따라서 공중날기를 얻은 플레이어는 이전 지역으로 빠르게 돌아가거나 잠긴 지역의 풍경과 일반 야생 포켓몬을 먼저 만날 수 있지만, 핵심 진행을 건너뛸 수는 없다.

다음 공간은 별도 설정이 없으면 비행 경계 예외를 허용하지 않는다.

- 리그와 사천왕 내부
- 퍼즐 중심 던전과 실내 구조물
- 아직 플레이어에게 해금되지 않은 다른 세대 차원
- 서버가 준비되지 않은 지역 또는 복구 중인 지역

### 4.2 포켓몬별 최대 Y

비행 가능한 포켓몬마다 절대 Y좌표 기준의 `max_y`를 설정한다.

- 포켓몬의 탑승 데이터에서 최대 Y를 읽는다.
- 현재 위치가 최대 Y에 도달하면 추가 상승 입력을 무시한다.
- 이미 한계를 넘은 경우 강제 하차시키지 않고 안전한 속도로 한계 아래까지 하강시킨다.
- 지형이 최대 Y보다 높아 이륙이나 이동이 불가능한 지역에는 별도 최소 보정 또는 비행 금지 안내를 둔다.
- 포켓몬의 종뿐 아니라 폼, 크기 또는 성장 단계별로 값을 다르게 둘 수 있다.
- 관리자·관전자 이동과 일반 포켓몬 탑승 제한을 분리한다.

수치 예시는 콘텐츠 데이터 작성 시 정하며, 소형 비행 포켓몬과 대형 비행 포켓몬의 체감 차이를 만드는 데 사용할 수 있다.

### 4.3 안전 규칙

- 천장, 나뭇잎과 구조물에 끼였을 때 안전한 위치를 탐색한다.
- 비행 중 포켓몬이 기절하거나 연결이 끊겨도 플레이어를 즉시 추락시키지 않는다.
- 최대 Y에서 강제 하차할 수 없다.
- 실내·리그·던전 비행 금지 구역 진입 시 경고 후 가까운 착륙점으로 유도한다.
- 엘리트라, 크리에이티브 비행과 다른 모드의 비행은 공중날기 예외로 인정하지 않는다.

## 5 파도타기와 수중 위험

### 5.1 모든 월드의 단독 수영 제한

모든 월드와 차원에서 플레이어가 두 블록 이상 깊이의 물을 맨몸으로 헤엄쳐 건널 수
없다. 물에 들어가면 다음 효과를 적용한다.

```text
제한 수역 진입
  → 정상 SURF 탑승 여부 검사
  → 미탑승이면 남은 공기 0 처리
  → 위쪽 수영 입력 제한
  → 아래 방향 침강력 적용
  → 경고 UI와 가장 가까운 안전한 물가 안내
```

모든 물 블록을 위험하게 만들면 마을 분수, 얕은 개울과 비 오는 지형까지 불편해진다. 다음 조건 중 하나를 만족하는 물만 `restricted_water`로 판정한다.

- 바다·심해 바이옴 태그
- 설정된 최소 수심 이상
- 지역 데이터에서 진행용 수로로 표시된 범위
- 파도타기 전용 경계 또는 구조물 구역

오버월드, 네더의 인공 수조, 던전과 모드 추가 차원에도 같은 판정을 적용한다. 한 블록
깊이의 얕은 물은 일반 마인크래프트 이동을 유지한다.

### 5.2 파도타기 탑승 효과

파도타기가 적용된 수상 포켓몬에 탑승하면 다음 효과를 제공한다.

- 공기 수치를 계속 최대로 유지해 무한 호흡처럼 보이게 한다.
- 포켓몬이 수면 높이를 유지하고 플레이어의 침강을 막는다.
- 수상 이동과 방향 전환을 포켓몬 탑승 조작으로 처리한다.
- `restricted_water` 경계를 정상적으로 통과할 수 있다.
- 필요하면 특정 포켓몬만 잠수 이동을 지원하고 별도 최대 수심을 둔다.

수면 위 하차는 다음 안전 규칙을 적용한다.

- 한 블록 깊이의 얕은 물이나 반경 2블록 안에 설 수 있는 육지가 있으면 정상 하차한다.
- 두 블록 이상 깊은 물에서 웅크리기 하차를 시도하면 취소하고 물가로 이동하라는 안내를 표시한다.
- 포켓몬 기절·회수처럼 강제로 분리되면 5틱 동안 전투 시작 여부를 확인한 뒤 마지막으로
  기록한 같은 차원의 안전한 육지로 구조한다. 기록이 없으면 같은 차원의 포켓몬센터
  체크포인트, 월드 스폰 순으로 사용한다.
- 수상 트레이너전으로 강제 하차한 경우에는 전투 중 현재 수면 위치와 공기를 유지하고
  기존 맨몸 물살을 적용하지 않는다. 전투 종료 후 파도타기 포켓몬에 재탑승하지 않았다면
  마지막 안전 지점으로 구조한다.

### 5.3 연출과 접근성

공기를 즉시 0으로 만들고 가라앉히는 규칙은 본가식 파도타기 관문을 명확하게 표현하지만 처음 접하는 플레이어에게는 갑작스러울 수 있다.

- 첫 제한 수역 접근 시 파도타기가 필요하다는 경고를 표시한다.
- 얕은 물에서는 이동 감속만 적용하고 깊은 물에서만 익사 규칙을 적용한다.
- 사망 직전에는 선택적으로 마지막 물가로 구조하는 난이도 설정을 제공한다.
- 화면 흔들림, 시야 효과와 경고음은 접근성 설정에서 낮출 수 있게 한다.

### 락클레임과 바다회오리

- 락클레임은 지역 진입 권한으로 사용하지 않는다. 플레이어가 권한을 보유하고 자연
  암벽에 닿으면 거미처럼 상승하며, 웅크리면 천천히 내려간다. 건물 벽에서 의도치
  않게 발동하지 않도록 획득 상태와 활성 상태를 분리하고 별도 단축키로 ON/OFF한다.
- 락클레임, 플래쉬, 괴력처럼 지속 동작하는 비전머신은 플레이어 개요에서도 ON/OFF할 수
  있다. 플래쉬는 보유 중이어도 OFF라면 플래쉬 요구 동굴에서 실명 상태를 유지한다.
- 해양 타일에 바다회오리 경계를 지정하면 같은 설정의 해양 타일 군집 외곽에만
  회오리가 표시된다. 파도타기 탑승 중 바다회오리 권한이 없으면 바깥쪽으로 밀려난다.
- 폭포오르기는 지원 비전머신 목록에서 제외한다.

### 괴력 바위 퍼즐

- 전용 블록 ID는 `cobbleventure_bootstrap:strength_boulder`와
  `cobbleventure_bootstrap:strength_plate`를 사용한다.
- 괴력 바위 아이템 하나를 배치하면 실제 충돌을 가진 `2×2×2` 멀티블록이 생성된다.
- 괴력을 보유하고 메뉴에서 `ON`으로 설정한 플레이어가 바위를 우클릭하면 바라보는
  수평 방향으로 한 칸 이동한다. 목적지에 블록이나 엔티티가 있으면 이동하지 않는다.
- 괴력 발판 위에 바위의 일부가 올라오면 레드스톤 신호 15를 출력한다. 채널은 사용하지
  않으며 여러 발판 조건은 바닐라 레드스톤 회로로 조합한다.
- `/cobbleventure_strength reset`은 로드된 차원의 온전한 괴력 바위를 최초 배치 위치로
  되돌린다. 초기 위치가 막힌 바위는 안전을 위해 건너뛴다.
- 건축전용 모드는 동일한 두 블록 ID와 동일한 모델을 등록한다. 따라서 건축 월드에서
  내보낸 구조물 NBT를 실제 플레이 모드가 별도 변환 없이 읽을 수 있다.

### 바위깨기 퍼즐

- 건축전용 모드에서 `cobbleventure_bootstrap:rock_smash_rock`을 직접 배치한다.
- 바위깨기를 보유하고 플레이어 메뉴에서 `ON`으로 설정한 플레이어가 우클릭하면
  서버가 바위를 제거하고 돌 파괴 효과를 재생한다.
- 전용 바위는 일반 채굴, 폭발과 피스톤으로 제거할 수 없어 진행 조건을 우회할 수 없다.
- 제거된 바위는 서버가 실제로 가동된 시간 기준 5분(6,000틱) 뒤 같은 위치에 자동
  복원된다. 위치가 블록이나 엔티티로 막혀 있거나 청크가 로드되지 않았다면 매초
  안전하게 재시도한다. 서버가 꺼진 동안에는 복원 시간이 흐르지 않는다.
- `/cobbleventure_rock_smash reset`은 대기 시간을 무시하고 해당 차원의 제거된 바위를
  즉시 복원한다. 이때도 막힌 위치는 안전하게 건너뛴다.
- 건축전용 모드와 실제 플레이 모드가 같은 블록 ID와 모델을 사용하므로 구조물 NBT에
  그대로 저장된다.

## 6 비전머신 해금

비전머신은 아이템 획득만으로 즉시 모든 포켓몬에 적용하지 않는다. 플레이어 권한, 포켓몬 적성과 적용 상태를 모두 확인한다.

예상 흐름:

```text
관장·퀘스트·이벤트 완료
  → 비전머신 아이템 또는 사용 권한 획득
  → PC나 파티 화면에서 대상 포켓몬 선택
  → 종·폼 적성 검사
  → 포켓몬 개체에 이동 능력 기록
  → 탑승 튜토리얼 활성화
```

비전머신을 소비성 아이템으로 할지 한 번 해금하면 반복 적용 가능한 키 아이템으로 할지는 미정이다. 서버 장기 운영과 포켓몬 교체를 고려하면 반복 사용 가능한 플레이어 권한 방식이 초기 권고안이다. 아이템으로 표시할 경우 [본가식 가방 인벤토리](BAG_INVENTORY.md)의 `중요한 물건` 포켓에 두고 판매·드롭·거래를 금지한다.

## 7 경계 검사 우선순위

```text
차원 진입 권한
  → 월드 READY 상태
  → 절대 비행·탑승 금지 구역
  → 정상 FLY 또는 SURF 탑승 예외
  → 관문·배지·진행 조건
  → 실패 시 체크포인트 복귀
```

공중날기는 같은 세대 월드 안의 지역 경계만 우회한다. 차원 해금, 리그 도전 자격과 관리자 보호 구역보다 우선하지 않는다.

## 8 프로토타입 범위

현재 프로토타입은 Cobblemon 1.7.3의 취소 가능한 탑승 직전 이벤트를 사용한다.
포켓몬 폼의 탑승 방식에 `LIQUID`가 있으면 `surf`, `AIR`가 있으면 `fly`
플레이어 플래그를 요구한다. 두 방식을 모두 지원하는 포켓몬은 둘 중 하나만 해금해도
탑승할 수 있지만, 탑승 후 Cobblemon이 실제로 선택한 `RidingStyle`별로 권한을 다시
검사한다. 파도타기 없이 `LIQUID`로 전환하거나 공중날기 없이 `AIR`로 전환하면 즉시
강제 하차시키며, 잠긴 방식이 실제로 선택되었을 때만 해당 비전머신 안내를 표시한다.
깊은 물에서 강제 하차한 경우에는 기존 구조 안전장치가 이어서 처리한다. `LAND` 방식은
제한하지 않는다.

모든 월드에서는 한 블록 깊이의 물만 맨몸 이동을 허용한다. 연속된 물기둥이
두 블록 이상이면 마지막 안전한 육지 방향으로 물살을 적용하고, 20틱 안에 빠져나오지
못하면 해당 육지로 복귀시킨다. 체력과 공기는 변경하지 않는다. `surf` 플래그를 가진
플레이어가 `LIQUID` 탑승 방식의 포켓몬에 실제로 탑승한 경우에는 월드 종류와 관계없이 이 처리를 완전히
건너뛴다. 주변에서 안전한 육지를 찾을 수 없는 예외 상황에는 수평 이동을 정지시켜
깊은 물을 계속 건너는 우회를 막는다. 수상 전투 때문에 파도타기 포켓몬이 회수된 동안에도
전투용 수면 보호가 우선하며, 전투가 끝날 때까지 물살 복귀를 적용하지 않는다.

관리자는 다음 명령으로 자신의 플래그를 시험할 수 있다.

```text
/cobbleventure_field_move surf on
/cobbleventure_field_move surf off
/cobbleventure_field_move fly on
/cobbleventure_field_move fly off
/cobbleventure_field_move flash on
/cobbleventure_field_move flash off
```

동굴 콘텐츠 JSON에서 `requires_flash`가 `true`인 구역에 들어가면 `flash`가 꺼진
플레이어에게 무한 실명을 적용한다. `flash`가 켜지면 실명을 제거하고 무한 야간 투시를
적용한다. 해당 동굴 구역 또는 차원에서 나오면 이 시스템이 적용한 효과를 즉시 제거한다.
동굴은 공유 던전 차원을 사용할 수 있으므로 차원 ID뿐 아니라 각 동굴의 `bounds`도 함께
검사한다.

1. 비행 가능 포켓몬 1종과 수상 이동 포켓몬 1종을 시험 데이터로 지정한다.
2. 비전머신 미적용 상태에서 해당 탑승을 거부한다.
3. 공중날기 적용 후 지역 경계를 관문 없이 넘는지 확인한다.
4. 최대 Y 도달 시 상승 제한과 안전 하강을 검증한다.
5. 제한 수역에서 미탑승 플레이어의 공기 0·침강·경고를 검증한다.
6. 파도타기 탑승 중 호흡 유지, 부력과 수상 이동을 검증한다.
7. 깊은 물 하차, 포켓몬 기절, 로그아웃과 서버 재시작을 시험한다.
8. 날아서 잠긴 체육관·리그 진행을 우회할 수 없는지 확인한다.

## 9 미결정 사항

- 공중날기와 파도타기를 어느 지역·관장 이후 해금할 것인가?
- 비전머신은 소비 아이템인가, 영구 플레이어 권한인가?
- 지상 탑승 능력·장비의 이름과 해금 조건은 무엇인가?
- 종·폼별 `max_y`와 비행 속도를 어떤 기준으로 정할 것인가?
- 비행으로 잠긴 지역의 야생 포켓몬과 아이템에 미리 접근하는 것을 허용할 것인가?
- 제한 수역의 최소 수심과 바이옴 태그는 무엇인가?
- 단독 입수 시 익사만 적용할지 자동 구조 옵션을 기본으로 둘 것인가?
- 파도타기 중 잠수와 수중 포켓몬 포획을 허용할 것인가?
