# 서바이벌 격자 세대 월드

> 적용 후보: 2안 서바이벌 격자 전용
>
> 관련 결정: D-03 관장 수, D-04 격자 도시 위치, D-07 리그 자격, D-13 아키텍처
>
> 설계 상태: 이전 방식 보존 / 격자 크기와 진행 규칙 미정

## 1 목적

세대 월드를 일반 마인크래프트 서바이벌처럼 자유롭게 탐험하면서, 황혼의 숲 랜드마크와 유사한 결정론적 격자에 마을·체육관을 생성한다.

지역 1→8, 바이옴 벽과 제한 통로를 사용하지 않는다. 플레이어는 채광, 건축, 농사와 포켓몬 탑승을 이용해 원하는 방향과 순서로 탐험한다.

## 2 공통 세대 구조

```text
generation_1 서바이벌 격자 월드
  → 리그 자격 획득
  → transition의 1세대 챔피언로드·리그
  → generation_2 서바이벌 격자 월드
```

세대별 독립 월드, 세대별 포켓몬 스폰과 전환·리그 월드는 다른 두 안과 동일하게 유지한다.

## 3 월드 규칙

- 게임 모드는 `SURVIVAL`이다.
- 블록 파괴·설치, 채광, 농사, 사냥, 건축과 자동화를 허용한다.
- 바이옴 사이에 강제 벽이나 논리 진행 경계를 두지 않는다.
- 마을과 체육관을 순차 지역에 묶지 않는다.
- Cobblemon의 일반 탑승을 비전머신으로 제한하지 않는다.
- 일반 수영을 허용하고 파도타기 전용 제한 수역을 만들지 않는다.
- 세대 차원 진입과 리그 진입 자격만 서버가 진행 상태로 검사한다.

## 4 격자 배치 모델

월드를 일정 크기의 랜드마크 셀로 나눈다.

```text
cell_x = floor(chunk_x / cell_size_chunks)
cell_z = floor(chunk_z / cell_size_chunks)
cell_seed = hash(world_seed, generation_id, cell_x, cell_z)
```

각 셀의 시드로 다음을 결정한다.

- 랜드마크 생성 여부
- 마을, 체육관, 복합 도시 또는 일반 구조물 유형
- 셀 중심에서의 X·Z 오프셋
- 구조물 회전과 변형
- 바이옴별 건축 프로필
- 관장·트레이너·상점 프로필

같은 월드 시드와 설정에서는 항상 같은 셀에 같은 후보가 생성된다.

## 5 구조물 후보 선택

```text
격자 셀 중심 계산
  → 허용 반경 안에서 지형·바이옴 조사
  → 구조물 프로필 후보 필터링
  → 충돌·경사·수면·높이 검사
  → 결정론적 후보 선택
  → 마을·체육관 복합 구조물 배치
  → 도시 ID와 앵커 저장
```

체육관만 마을에서 떨어져 생성되지 않도록 마을과 체육관은 하나의 도시 구조물 또는 연결된 직소 구조물 집합으로 배치한다.

| 바이옴 조건 | 구조물 예시 |
|-------------|-------------|
| 평원·숲 | 일반 마을, 목조 체육관 |
| 사막·악지 | 오아시스 도시, 사암 체육관 |
| 설원 | 방한 마을, 얼음 체육관 |
| 산악 | 계단 도시, 절벽 체육관 |
| 해안 | 항구 마을, 수상 체육관 |

해당 셀에서 적합한 지형을 찾지 못하면 다음 중 설정된 정책을 사용한다.

1. 같은 셀 안의 대체 바이옴 프로필
2. 인접 셀로 후보 이동
3. 해당 랜드마크 생략 후 다음 유효 셀에서 보정 생성
4. 관리자 확인이 필요한 실패 상태 기록

## 6 격자 반복감 완화

논리 셀은 규칙적이어도 실제 구조물 위치는 셀 안에서 오프셋을 적용한다.

- 셀마다 중심 오프셋과 회전을 시드로 변화시킨다.
- 모든 셀에 랜드마크를 만들지 않고 밀도 규칙을 둔다.
- 마을 사이에 유적, 자연 랜드마크와 빈 셀을 섞는다.
- 지도와 나침반은 정확한 좌표 대신 탐색 범위 또는 방향을 안내할 수 있다.
- 구조물 간 최소 거리를 검증해 셀 경계에서 서로 겹치지 않게 한다.

## 7 체육관 진행 후보

비선형 월드이므로 1·3안의 고정 관장 순서를 그대로 사용할 수 없다.

| 방식 | 설명 | 주의점 |
|------|------|--------|
| 고정 난이도 | 체육관마다 고유 레벨을 두고 플레이어가 위험을 감수해 자유 도전 | 초반에 고난도 관장을 먼저 만날 수 있음 |
| 배지 스케일링 | 보유 배지 수에 따라 관장 팀이 변경 | 팀 데이터 제작량과 악용 검증 필요 |
| 권역 단계 | 격자 거리 또는 세대 월드 중심에서 멀수록 강해짐 | 사실상 약한 선형성이 생김 |
| 필요 배지 수 | 발견 순서는 자유지만 특정 수의 배지를 모으면 리그 해금 | 가장 단순하나 관장별 서사 순서가 약함 |

관장 수, 중복 도시 처리와 리그에 필요한 배지 수는 아키텍처 선택 후 결정한다.

## 8 리그 이동

리그는 세대 월드의 무작위 격자 구조물로 만들지 않고 전환 월드에 유지한다. 플레이어가 요구 배지 또는 세대 완료 조건을 충족하면 다음 중 하나로 진입한다.

- 월드 스폰 근처의 고정 리그 터미널
- 지도에서 찾는 하나의 리그 관문 구조물
- 모든 포켓몬 센터에서 사용할 수 있는 이동 서비스
- 아이템 또는 명령 UI를 통한 챔피언로드 이동

비선형 탐색이더라도 전환 월드부터 다음 세대로 이어지는 순서는 유지한다.

## 9 서바이벌 보호와 운영

- 도시 핵심 블록, 관장과 진행 장치는 파괴를 막거나 복구할 수 있어야 한다.
- 도시 외부에서는 일반 건축을 허용한다.
- 격자 셀 생성 전에 다른 모드 구조물과 충돌을 검사한다.
- 이미 생성된 청크에는 자동으로 도시를 덮어쓰지 않는다.
- 도시 ID는 세대, 셀 좌표와 구조물 프로필로 생성한다.
- 누락·파괴된 도시와 NPC를 셀 앵커 기준으로 복구한다.
- 플레이어 건축물 근처의 복구 작업은 미리보기와 관리자 승인을 요구한다.

## 10 프로토타입 범위

1. 시험 세대 차원을 서바이벌 모드로 만든다.
2. 2×2 또는 3×3 격자 셀을 계획한다.
3. 서로 다른 바이옴 프로필의 마을·체육관 2개를 생성한다.
4. 같은 시드에서 위치와 구조물 선택이 재현되는지 확인한다.
5. 자유 채광·건축·수영·탑승이 가능한지 확인한다.
6. 비전머신과 지역 경계 검사 없이 도시를 자유로운 순서로 방문한다.
7. 도시 핵심 구조물 보호와 복구를 시험한다.
8. 임시 배지 조건을 충족한 뒤 전환 월드 리그로 이동한다.

## 11 미결정 사항

- 격자 셀 크기와 랜드마크 생성 밀도는 얼마인가?
- 세대 월드마다 체육관을 정확히 몇 개 보장할 것인가?
- 관장 난이도를 고정, 배지 스케일링 또는 거리 단계 중 무엇으로 할 것인가?
- 리그 입장에 필요한 배지 수와 관장 조합은 무엇인가?
- 도시 구조물을 플레이어가 어디까지 변경할 수 있는가?
- 격자 도시와 바닐라·다른 모드 마을을 함께 허용할 것인가?
- 장거리 탐색 피로를 줄일 지도·나침반·이동 수단은 무엇인가?
