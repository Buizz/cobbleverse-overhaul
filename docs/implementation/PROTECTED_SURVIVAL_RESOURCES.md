# 보호형 서바이벌 필드와 재생 자원

> 관련 기능: F-16 보호형 서바이벌과 재생 자원
>
> 관련 결정: D-22 세대 월드 게임 모드와 환경 보호 방식
>
> 설계 상태: 방향 확정 / 권한 API·작물·광물표와 재생 주기 미정

## 1 목적

세대 월드, 던전과 리그 차원에서 `ADVENTURE` 모드를 강제하지 않고 플레이어를 `SURVIVAL` 모드로 유지한다. 대신 서버 권위의 영역·행동 권한 시스템이 자연환경과 진행 구조물을 보호한다.

```text
기본 정책
  → 블록 파괴·설치·상태 변경 거부

명시적 허용
  → 필드의 지정 작물 수확
  → 개인 농장의 허용 농사·꾸미기
  → 특수 던전의 재생형 광물 노드 채굴
  → 퍼즐에 필요한 제한 상호작용
```

목표는 포켓몬 본가식 필드를 보존하면서도 작물 수확과 광물 채굴 같은 Minecraft의 손맛을 선택적으로 되살리는 것이다.

## 2 확정 게임 모드

| 공간 | 게임 모드 | 기본 블록 정책 | 예외 |
|------|-----------|----------------|------|
| 세대 필드 | `SURVIVAL` | 파괴·설치·환경 변경 금지 | 지정 작물, 스토리 상호작용 |
| 마을·체육관·리그 | `SURVIVAL` | 파괴·설치 금지, 구조물과 장식 보호 | 문, 버튼, NPC, 허용 퍼즐 |
| 특수 던전 | `SURVIVAL` | 파괴·설치 금지, 지형·필수 구조물 보호 | 재생 광물 노드 채굴, 지정 작물, 퍼즐 상호작용 |
| 공용 인스턴스 | `SURVIVAL` + 인스턴스 보호 | 파괴·설치 금지, 템플릿 변경 금지 | 인스턴스 정의의 허용 상호작용 |
| 개인 농장 | `SURVIVAL` + 소유권 보호 | 타인·금지 블록 변경 금지 | 소유자의 농사와 제한된 꾸미기 |

플레이어의 블록 설치는 세대 필드, 마을, 체육관, 리그, 던전과 공용 인스턴스에서 전면 금지를 기본값으로 한다. 현재 기준에서 설치가 가능한 유일한 일반 플레이 공간은 개인 농장이며, 그곳에서도 허용 목록에 등록된 농사·장식 블록만 소유 플롯 안에 놓을 수 있다.

게임 모드는 플레이어 조작 호환성을 제공할 뿐 권한의 근거가 아니다. 실제 허용 여부는 서버가 매 행동마다 판단한다.

## 3 서버 권한 판정

권한 시스템은 기본 거부 방식으로 구성한다.

```text
플레이어 행동 요청
  → 현재 차원과 영역 조회
  → 진행·소유권·관리 권한 확인
  → 행동 종류와 대상 블록 태그 확인
  → 도구·성숙도·재생 상태 검사
  → 허용 시 서버에서 실행·드롭 지급
  → 거부 시 월드 상태 복원·안내
```

```text
WorldActionPolicy
  dimension_profile
  region_id
  action_type
  allowed_block_tags
  denied_block_tags
  required_progress
  required_tool_tags
  owner_scope
  cooldown_profile
  drop_profile
```

### 3.1 검사해야 할 행동

블록 파괴 이벤트만 취소하면 다음 방식으로 환경을 훼손하거나 관문을 우회할 수 있다. 모두 같은 정책 계층에서 검사한다.

- 블록 파괴와 설치
- 물·용암·가루눈 양동이 사용과 유체 흐름
- 부싯돌, 불, 화염 확산과 용암 화재
- TNT, 침대, 리스폰 앵커와 다른 폭발
- 피스톤·점착 피스톤에 의한 경계 밖 블록 이동
- 나무 성장, 뼛가루, 거대 버섯과 구조물 생성
- 경작지 밟기, 흙 갈기, 길 블록 변경과 블록 벗기기
- 엔더맨·몹·포켓몬·보스의 환경 훼손
- 광차, 보트, 갑옷 거치대와 엔티티 설치
- 다른 모드의 채굴기, 빌더, 월드 브레이커와 자동화 블록
- 명령어, 월드에딧과 관리자 우회 권한

관리자 우회는 명시적인 권한 노드와 감사 로그를 사용한다. 단순 크리에이티브 모드 여부만으로 자동 허용하지 않는다.

## 4 필드 작물 수확

세대 필드의 열매나 특수 작물은 월드 장식이면서 수확 가능한 자원 노드다.

### 4.1 기준 규칙

- 데이터 태그 `#cobbleventure:field_harvestable`에 등록된 블록만 수확할 수 있다.
- 성숙 단계에 도달한 작물만 허용한다.
- 씨앗이나 줄기까지 제거하지 않고 수확 상태로 되돌리거나 자동 재식재한다.
- 드롭은 월드에 흩뿌리기보다 [본가식 가방 인벤토리](BAG_INVENTORY.md)의 대응 포켓에 서버가 직접 지급한다.
- 동일 작물의 개인별·서버 공용 재생 여부를 프로필로 설정한다.
- 수확 후 외형을 미성숙 상태로 바꾸고 재생 완료 시 다시 활성화한다.
- 필수 진행 아이템은 경쟁적인 공용 선착순 작물에만 배치하지 않는다.

### 4.2 상태 범위

| 방식 | 장점 | 주의점 | 사용 후보 |
|------|------|--------|-----------|
| 서버 공용 작물 | 월드 변화가 모두에게 자연스럽게 보임 | 한 플레이어가 독점 가능 | 흔한 작물, 짧은 재생 |
| 플레이어별 작물 | 각 플레이어에게 동일한 기회 제공 | 외형 동기화와 가상 드롭 구현 필요 | 퀘스트·희귀 작물 |
| 혼합 | 중요도별로 선택 가능 | 데이터와 UI가 복잡 | 기준안 |

## 5 특수 던전과 자연 동굴 대체

일반 세대 월드의 자연 동굴은 주요 채굴 콘텐츠로 사용하지 않는다. 접근을 막거나 비진행 공간으로 두고, 이름 있는 특수 던전이 자연 동굴 탐험과 채광의 역할을 대신한다.

```text
세대 필드의 동굴 입구
  → 달맞이산·암석터널 등 특수 던전
  → 포켓몬·트레이너·퍼즐 탐험
  → 지정 자원 구역의 고정 광물 노드
  → 채굴·가방 지급
  → 같은 자리의 다음 광물 상태 재추첨
```

던전 전체 벽을 자유롭게 캘 수 있게 하지 않는다. 필수 동선, 경계와 구조물은 보호하고 `resource_node`로 생성된 광물만 채굴할 수 있다. 따라서 벽을 뚫어 퍼즐이나 관문을 우회하는 문제를 피하면서 광물을 캐는 경험을 제공할 수 있다.

## 6 재생형 광물 노드

광물 노드의 좌표는 던전 설계 단계에서 고정한다. 플레이어가 노드를 캐면 현재 광물의 보상을 지급하고, 같은 좌표에 나타날 다음 광물 상태를 가중치로 다시 추첨한다. 위치를 찾아 헤매는 일반 광맥보다 방송 서버의 반복 채집 지점을 만들기 쉽고, 구조물과 진행 동선을 훼손하지 않는다.

```text
FixedOreNodeDefinition
  node_id
  dungeon_id
  anchor
  ore_pool_by_progress
  reroll_delay
  depleted_state
  required_progress
  required_tool
  ownership_scope
  drop_profile

FixedOreNodeState
  node_id
  current_ore
  revision
  next_roll_at
  last_mined_by
```

### 6.1 채굴 후 재추첨 흐름

```text
고정 노드 채굴 요청
  → node_id, 현재 revision과 활성 상태 검사
  → 노드를 원자적으로 잠금
  → 현재 광물의 드롭을 정확히 한 번 지급
  → 고갈 블록 또는 짧은 대기 상태로 전환
  → 진행 단계에 맞는 광물 풀에서 가중치 추첨
  → 같은 좌표에 다음 광물을 배치하고 revision 증가
  → 저장·클라이언트 동기화 후 잠금 해제
```

`광물 없음`, 돌 또는 고갈 수정 같은 상태도 광물 풀의 결과로 둘 수 있다. 기본안은 짧은 재추첨 지연을 사용해 한 자리에서 초고속으로 무한 채굴하는 일을 막는다. 서버 재시작 시에는 현재 광물, `revision`과 다음 재추첨 시각을 복구한다.

### 6.2 채굴과 드롭

- 등록된 활성 노드만 파괴를 허용한다.
- 필요한 곡괭이 등급과 스토리 진행을 검사한다.
- 현재 노드 상태의 서버 드롭 테이블을 적용하고 지급이 끝난 뒤에만 다음 상태로 전환한다.
- 본가식 가방에서 광물을 사용할 계획이면 `재료` 포켓으로 직접 지급한다.
- 행운, 섬세한 손길, 폭발 채굴과 자동 채굴기의 적용 여부를 프로필별로 제한한다.
- 일반 플레이어는 던전에 광물이나 다른 블록을 설치할 수 없다. 그래도 관리자 명령, 월드 복구와 다른 모드의 블록 배치에 대비해 `node_id`가 없는 광물은 자원 노드로 인정하지 않는다.
- 두 플레이어가 동시에 캐더라도 `revision`이 일치한 첫 요청만 성공하게 해 중복 드롭을 막는다.

### 6.3 광물 풀과 소유 범위

| 항목 | 기준안 |
|------|--------|
| 좌표 | 구조물에 심은 고정 `node_id` 앵커 |
| 다음 광물 | 던전·세대·배지 단계별 가중치 풀에서 추첨 |
| 반복 결과 | 같은 광물 연속 허용 여부를 노드 프로필로 설정 |
| 재추첨 시점 | 채굴 직후 또는 짧은 고갈 대기 후 |
| 공유 범위 | 서버 공용 노드를 기본으로 사용 |
| 희귀 광물 | 후반 진행에서 가중치 또는 전용 노드 해금 |
| 독점 방지 | 노드 지연, 플레이어별 보상 쿨다운과 시간당 상한 조합 |

플레이어별로 서로 다른 광물이 보이는 가상 노드는 외형 동기화가 복잡하므로 첫 구현에서는 제외한다. 공용 노드가 방송 서버의 채집 거점과 경쟁을 만들되, 필수 진행 재료는 이 경쟁에만 의존하지 않게 한다.

## 7 자연환경 보호와 시각적 피드백

권한 거부가 단순히 블록이 되돌아오는 형태면 버그처럼 느껴진다.

- 보호된 블록에는 파괴 금지 아이콘이나 짧은 안내를 표시한다.
- 수확·채굴 가능한 대상에는 윤곽선, 반짝임, 입자 또는 도구 도움말을 제공한다.
- 잘못된 도구에는 필요한 도구와 진행 조건을 알려준다.
- 미성숙 작물과 재생 중 광물에는 남은 시간 또는 상태를 표시할 수 있다.
- 처음 입장할 때 `일반 지형은 보호되며 표시된 자원만 채집 가능`하다는 규칙을 안내한다.

## 8 진행·경제 연결

- 초반 던전은 기본 광물과 규토리 관련 재료를 제공한다.
- 후반 던전은 진화·포켓몬 육성·장식에 필요한 희귀 광물을 포함할 수 있다.
- 메인 스토리 필수 아이템은 낮은 확률 광물 채굴에만 의존하지 않는다.
- 광물에는 상점 구매, 퀘스트 보상 또는 트레이너 보상 같은 대체 획득처를 둔다.
- 배지나 비전머신으로 새로운 자원 방·광물 풀을 해금할 수 있다.
- 개인 농장, 던전 채굴과 상점이 같은 재화를 과잉 공급하지 않게 경제표에서 함께 계산한다.

## 9 구현 경계

영역 보호 모드를 그대로 사용할 수도 있지만 프로젝트 진행 상태와 인스턴스·작물·가방을 연결해야 하므로 코어 모드에 통합 권한 API가 필요하다. 외부 보호 모드는 토지 선택·시각화·관리 명령 등 보조 기능으로 검토한다.

```text
외부 보호·클레임 API
  → 영역과 기본 파괴·설치 차단

Cobbleventure 게임 어댑터
  → 진행 상태, 작물 성숙도, 자원 노드, 가방 지급과 예외 판정
```

허용 규칙은 코드에 흩어놓지 않고 데이터 태그와 영역 프로필로 관리한다.

## 10 프로토타입

첫 지역과 작은 시험 던전에 다음을 구현한다.

1. 개인 농장의 허용 블록을 제외하면 세대 필드·마을·리그·던전·공용 인스턴스 어디에도 블록을 설치할 수 없다.
2. 성숙한 필드 작물 하나는 수확되고 자동으로 재생된다.
3. 던전의 고정 좌표 세 곳에 서로 다른 `node_id` 광물 노드를 배치한다.
4. 등록된 광물 노드만 곡괭이로 채굴할 수 있다.
5. 채굴 결과가 가방 재료 포켓에 정확히 한 번 들어가고 같은 자리의 다음 광물이 가중치대로 바뀐다.
6. 짧은 고갈 상태와 플레이어별 상한이 연속 채굴 속도를 제한한다.
7. 물·용암, 불, 폭발, 피스톤과 자동 채굴기로 보호 구역을 훼손할 수 없다.
8. 서버 재시작 후 작물과 광물의 현재 상태·재추첨 시각이 유지된다.

### 합격 기준

- 일반 자연환경과 필수 구조물을 어떤 허용 도구로도 훼손할 수 없다.
- 허용 작물과 광물은 지연·고스트 블록 없이 자연스럽게 수확·채굴된다.
- 두 플레이어의 동시 채굴로 중복 드롭이 발생하지 않는다.
- 보호 거부와 허용 대상이 UI로 구분된다.
- 재생으로 구조물, 포탈, NPC와 다른 자원 노드를 덮어쓰지 않는다.
- 관리자 명령으로 노드 상태 조회·재생·비활성화가 가능하다.

## 11 미결정 사항

- 세대 필드의 수확 가능 작물 목록은 무엇인가?
- 작물과 광물 상태는 서버 공용·플레이어 개인·파티 중 어떤 범위인가?
- 던전별 고정 노드 수, 광물 가중치, 재추첨 지연과 시간당 채굴 상한은 얼마인가?
- 곡괭이와 일반 도구를 가방 퀵슬롯에서 어떻게 장착·사용할 것인가?
- 행운, 섬세한 손길과 다른 모드 채굴 효과를 허용할 것인가?
- 자연 동굴 입구를 완전히 막을 것인가, 비자원 탐험 공간으로 남길 것인가?
- 외부 보호 모드를 사용할 것인가, 코어 모드가 모든 영역 판정을 담당할 것인가?
- 플레이어가 보호된 블록을 오래 때릴 때 발생하는 패킷·시각 효과를 어떻게 처리할 것인가?
