# 진행 및 콘텐츠 해금

> 관련 요구사항: F-06, F-07
>
> 관련 결정: D-02, D-03, D-06
>
> 설계 상태: 개요 작성 / 상세 조사 전

## 범위

- 지방, 관장, 배지와 지역 완료 상태
- 지방 완료에 따른 포켓몬 출현군과 상점 단계 해금
- 월드 공용 상태와 플레이어 개인 상태의 경계
- 진행 이벤트, 중복 지급 방지와 버전 이관

## 현재 원칙

- 관장 승리 기록과 최초 보상은 플레이어별로 관리한다.
- 월드 콘텐츠 단계는 서버 전체가 공유하는 상태로 관리하는 안을 우선 검토한다.
- 해금 상태 변경은 명시적 이벤트로 발행해 스폰, 상점과 안내 시스템이 같은 결과를 보게 한다.
- 저장 데이터에는 스키마 버전을 두고 마이그레이션 절차를 제공한다.

## 다음 결정

- 첫 지방과 관장 수
- 포켓몬 해금의 공용·개인 범위
- 지방 완료 조건과 순서 강제 수준
- 파티 교체, 거래와 교배를 통한 해금 우회 정책
