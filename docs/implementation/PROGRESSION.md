# 진행 및 콘텐츠 해금

> 관련 요구사항: F-06, F-07
>
> 관련 결정: D-02, D-03, D-06
>
> 설계 상태: 개요 작성 / 상세 조사 전
>
> 적용 후보: 현재 내용은 1안 어드벤처와 3안 하이브리드 기준. 2안의 비선형 진행은 별도 확정 필요.

## 범위

- 세대 월드의 탐험 지역 1~8, 관장 8명, 배지와 지역 완료 상태
- 지역별 관장 승리에 따른 다음 관문, 포켓몬 출현군과 상점 단계 해금
- 8번째 지역 완료 후 챔피언로드·리그 포탈 활성화
- 월드 공용 상태와 플레이어 개인 상태의 경계
- 진행 이벤트, 중복 지급 방지와 버전 이관

## 현재 원칙

- 관장 승리 기록과 최초 보상은 플레이어별로 관리한다.
- 기본 진행 경로는 지역 1→2→3→4→5→6→7→8 순서로 고정한다.
- 각 지역의 관장 승리를 다음 지역 관문 해제 조건으로 사용한다.
- 8번째 관장 승리 후에만 리그 포탈을 활성화한다.
- 공중날기와 파도타기 비전머신 해금은 플레이어별 진행 상태로 관리한다.
- 공중날기는 물리적 지역 경계를 우회하지만 체육관·상점·리그의 진행 잠금은 해제하지 않는다.
- 월드 콘텐츠 단계는 서버 전체가 공유하는 상태로 관리하는 안을 우선 검토한다.
- 해금 상태 변경은 명시적 이벤트로 발행해 스폰, 상점과 안내 시스템이 같은 결과를 보게 한다.
- 저장 데이터에는 스키마 버전을 두고 마이그레이션 절차를 제공한다.
