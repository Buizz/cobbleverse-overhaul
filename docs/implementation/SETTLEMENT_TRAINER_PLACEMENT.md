# 마을 중심 트레이너 배치 계획

## 목적

트레이너 편집 화면에서 마을 좌표를 직접 입력하는 대신, 마을이 자신의 슬롯·구역·허용 트레이너 풀을 관리하게 한다. 실제 스폰 구현은 바이옴·벽·건물·규모 작업이 끝난 다음 진행한다.

- 관련 기능: `TRAINER-PLACEMENT-01`
- 결정: `DEC-TRAINER-010` — 트레이너는 마을의 배치 계획을 통해 생성한다.
- 상태: 후속 구현 예정

## 배치 종류

| 종류 | 예 | 정책 |
|---|---|---|
| 필수 슬롯 | 관장, 라이벌, 안내 NPC | 고정 ID, 영구 생성, 앵커 기반 |
| 고정 도전자 | 체육관 앞 트레이너 | 슬롯 또는 건물 연결점에 고정 |
| 구역 배치 | 광장·주거·공원 트레이너 | 허용 풀에서 선택, 제한 반경 배회 |
| 시간대 배치 | 낮 학생, 밤 직장인 | 조건에 따라 활성화 |

## 마을 데이터 계약

기존 `npc_placement`를 확장하여 다음을 관리한다.

- 전체 NPC 및 전투 트레이너 예산
- 필수 슬롯과 연결 앵커
- 구역별 최대 수량과 허용 `settlement_role`
- 허용 `trainer_class` 또는 트레이너 풀
- 고정, 제한 배회, 순찰 경로
- 패배·퀘스트·시간대에 따른 활성 조건
- 중복 생성 방지용 안정적인 배치 ID

트레이너 JSON은 외형·대화·팀·전투 설정을 소유하고, 마을 JSON은 어디에 누구를 배치할지 소유한다.

### EasyNPC 전투 멤버

`trainer_slots`의 각 슬롯은 전투를 제공하는 `trainer_id`와 실제 월드에 생성할
`members`를 분리한다. 각 멤버는 EasyNPC 외형·행동을 가져올 `npc_profile`,
안정적인 멤버 ID, 위치와 회전을 가진다.

- `battle_type: singles`는 `members`를 정확히 한 명 입력한다.
- `battle_type: doubles`는 `members`를 정확히 두 명 입력한다.
- 두 멤버는 별도 EasyNPC 엔티티로 생성하지만 같은 슬롯 ID와 전투 세션에 묶는다.
- 전투 팀, AI, 보상과 승리 플래그는 슬롯의 `trainer_id`가 한 번만 소유한다.
- 한 멤버가 없거나 로딩되지 않았으면 듀얼배틀을 시작하지 않는다.
- 두 NPC 중 누구와 상호작용해도 동일한 전투와 진행 상태를 사용한다.

예시는 다음과 같다.

```json
{
  "id": "rocket_duo",
  "trainer_id": "cobbleventure:trainer/rocket_duo",
  "battle_type": "doubles",
  "members": [
    {
      "id": "primary",
      "npc_profile": "cobbleventure:trainer/rocket_jessie",
      "position": { "x": 100, "y": 64, "z": 100 },
      "rotation": 180
    },
    {
      "id": "partner",
      "npc_profile": "cobbleventure:trainer/rocket_james",
      "position": { "x": 102, "y": 64, "z": 100 },
      "rotation": 180
    }
  ],
  "spawn_policy": "persistent",
  "tags": ["trainer", "pair"]
}
```

## 런타임 순서

1. 마을 생성 상태가 `READY`인지 확인한다.
2. 건물·도로가 만든 실제 앵커와 구역을 읽는다.
3. 필수 슬롯을 먼저 생성하고 저장 ID를 기록한다.
4. 남은 예산으로 구역별 트레이너 풀을 결정적으로 선택한다.
5. 재접속·청크 재로딩 시 저장 ID로 중복 생성을 막는다.
6. 구조물 버전이 바뀌면 이전 배치 상태를 명시적으로 마이그레이션한다.

## 선행 조건

- 마을 좌표와 앵커의 JSON 단일화
- 건축 키트의 NPC 연결점 메타데이터
- 트레이너 네 분류 축 카탈로그
- 마을 경계와 안전한 보행 가능 영역
- RCT 출력 어댑터와 자체 AI 런타임 난이도 매핑

## 후속 구현 완료 기준

- 마을 편집기에서 트레이너를 검색해 슬롯 또는 풀에 추가할 수 있다.
- 전투 방식에 따라 EasyNPC 멤버를 싱글 1명, 듀얼 2명으로 입력하고 검증할 수 있다.
- 같은 월드를 여러 번 불러와도 NPC가 복제되지 않는다.
- 관장은 정확히 한 명 생성되고 체육관 앵커를 사용한다.
- 배회 NPC가 벽·건물·낭떠러지 밖으로 이동하지 않는다.
- 제거·재배치·복구 명령이 제공된다.
