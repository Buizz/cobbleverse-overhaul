# 플레이어 챔피언 시스템

> 관련 요구사항: F-10
>
> 관련 결정: D-09, D-10
>
> 설계 상태: 개요 작성 / 상세 조사 전

## 범위

- 챔피언 도전 자격과 신청
- 공식 PvP 매치와 결과 확정
- 서버 통합 챔피언 상태와 공석 처리
- 최소 유지 시간, 일일 보상과 악용 방지

## 현재 원칙

- 첫 버전은 서버 통합 챔피언 1명으로 제한한다.
- 온라인 실시간 대전을 우선하며 오프라인 AI 방어는 후속 범위로 둔다.
- 매치 시작 전 참가자와 규칙을 고정하고 중단·무효·기권 상태를 구분한다.
- 일일 보상은 최소 유지 시간과 중복 수령 방지 상태를 확인한다.

## 다음 결정

- 도전자 선정과 대전 예약 방식
- 연결 종료와 서버 장애 판정
- 챔피언 장기 부재와 공석 처리
- 담합, 반복 양도와 다중 계정 악용 방지
