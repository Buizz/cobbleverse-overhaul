# 경제 및 보상

> 관련 요구사항: F-02, F-03, F-08, F-09
>
> 관련 결정: D-07, D-08
>
> 설계 상태: 자체 가방 연동 상점 1차 구현

## 범위

- 일반 상점과 체육관 도시 상점의 역할
- 배틀타워 판매 목록과 고유 가치
- 트레이너·관장 최초 보상과 반복 보상
- 사탕, 디스크, 병뚜껑과 네더라이트의 공급·소비 구조

## 현재 원칙

- 일반 상점은 기본 보급, 배틀타워는 도전 보상과 희귀 성장 자원을 담당한다.
- 최초 보상과 반복 보상을 분리해 중복 지급을 방지한다.
- 고급 재화에는 획득처뿐 아니라 지속적인 소비처를 함께 설계한다.
- 가격과 수량은 설정값으로 유지하고 변경 이력을 기록한다.

## 자체 상점 거래 경계

- 상점 NPC의 외형과 월드 배치는 기존 시설 시스템이 담당한다.
- NPC 우클릭부터는 Cobbleventure 상점 화면과 서버 거래 세션이 처리한다.
- CobbleDollars는 잔액 저장에만 사용하며 아이템 지급·회수에는 관여하지 않는다.
- 구매 상품 지급과 플레이어 판매 회수는 모두 `BagApi`를 통과한다.
- 서버는 상점 NPC와의 거리, 세션 토큰, 상품 인덱스, 수량, 잔액과 가방 수량을
  거래 시점에 다시 검사한다.
- 상품의 `sell_price`가 없으면 구매가의 50%를 기본 판매가로 사용한다.
- `sell_price`가 `0`인 상품은 구매만 가능하다.
