# 운영·호환성 및 배포

> 관련 요구사항: 프로젝트 기획서 6장·7장·9장·10장
>
> 관련 결정: D-01, D-05
>
> 설계 상태: 개요 작성 / 상세 조사 전

## 범위

- 도시, NPC, 진행과 챔피언 상태 조회·복구
- 백업, 저장 데이터 마이그레이션과 장애 대응
- Minecraft, Fabric, Cobblemon과 선택 어댑터·호환성 프로필의 버전 호환성
- 설치, 업데이트, 배포 파일 구성과 라이선스

## 현재 원칙

- 개발 착수 시 지원 버전 하나를 고정하고 호환성 프로필을 작성한다.
- 업데이트는 기존 월드와 플레이어 건축물을 자동으로 덮어쓰지 않는다.
- 관리자 명령은 조회, 검증, 복구와 강제 변경을 구분하고 감사 로그를 남긴다.
- 원본 모드팩, 모드, 데이터팩과 구조물 에셋은 각 라이선스가 허용하는 방식으로만 배포한다.
- 강제 청크 로딩을 기본 동작으로 사용하지 않는다.

## 다음 결정

- 지원할 배포 채널과 정확한 버전
- 새 월드와 기존 월드 지원 범위
- 백업 단위와 마이그레이션 실패 시 롤백 방식
- 공개 배포물에 포함할 파일과 외부 의존성 선언 방식
