# 세대 월드 아키텍처 결정 및 3안 비교 기록

> 관련 요구사항: F-01, F-07, F-11, F-12
>
> 관련 결정: D-13 세대 월드 아키텍처, D-14 하이브리드 서바이벌 범위
>
> 설계 상태: 3안 하이브리드 선택 / 1·2안은 비교 기록과 비상 대안으로 보존

## 0 결정 요약

2026년 7월 22일, 당시 `Cobbleverse Adventure`였던 현재 `Cobbleventure`의 기준 아키텍처로 **3안 하이브리드**를 선택했다.

```text
세대별 보호형 서바이벌 월드
  → 순차 8지역·체육관·비전머신
  → 전환 월드·챔피언로드·리그
  → 다음 세대 월드

시작 마을의 자기 집 PC
  → 공유 농장 차원의 개인 1청크 플롯
  → 규토리·나무열매 재배와 소규모 꾸미기
```

넓은 자유 서바이벌 월드는 현재 범위에서 제외한다. PC 공간은 1청크 개인 농장을 기준으로 하며, 채광·허기·몬스터 사냥·대규모 자동화는 제공하지 않는다. 1안과 2안은 구현 대상이 아니라 향후 범위 변경 또는 기술적 실패에 대비한 비교 기록으로 유지한다.

## 1 결정 목적

세대별 월드와 세대 사이 전환·리그 월드는 모든 안에 공통으로 유지한다. 결정할 것은 세대 월드에서 마인크래프트 생존 경험과 포켓몬 본가식 진행 중 어느 쪽을 중심에 둘 것인가이다.

```text
모든 안의 공통 구조

1세대 월드
  → 1세대 전환 월드·챔피언로드·리그
  → 2세대 월드
  → 2세대 전환 월드·챔피언로드·리그
  → 다음 세대 ...
```

아래 표는 선택 근거를 보존하기 위한 비교 기록이다. 구현 계획과 완료 기준은 3안을 기준으로 작성한다.

## 3 1안: 어드벤처 월드

### 3.1 정의

세대 월드를 포켓몬 본가의 필드처럼 만든다. 플레이어는 어드벤처 모드로 지역 1부터 8까지 이동하고, 관장·비전머신·리그를 통해 진행한다.

```text
지역 1 → 지역 2 → ... → 지역 8 → 전환 월드·리그
```

### 3.2 포함 요소

- 순차 지역 8개와 지역별 체육관 도시
- 지역마다 설정된 바이옴 풀
- 벽, 산맥, 절벽, 바다와 제한된 관문
- 비전머신 기반 탑승
- 공중날기의 지역 경계 자유 통과
- 파도타기 없이는 건널 수 없는 제한 수역
- 트레이너, 포켓몬 포획, 상점, 관장과 스토리 던전
- 세대별 포켓몬 스폰과 리그 전환 월드

### 3.3 제외 요소

- 집 PC를 통한 별도 서바이벌 월드
- 일반적인 채광, 벌목, 농사와 자유 건축
- 마인크래프트식 생존 사냥과 자원 파밍
- 자동화 설비와 대규모 생산 기지
- 자원 파밍을 목적으로 반복하는 일반 던전 조합

달맞이산처럼 포켓몬 원작의 진행을 재현하는 스토리 던전은 유지할 수 있다. 제외 대상은 마인크래프트 자원 파밍을 위한 던전·채굴 루프다.

### 3.4 장점

- 포켓몬 본가에 가장 가까운 진행과 이동 경험
- 플레이어가 벽을 파거나 쌓아 관문을 우회하지 못함
- 지역, 관장, 비전머신과 포켓몬 출현 레벨을 정교하게 설계 가능
- 건축·자동화 모드로 인한 진행 및 경제 붕괴가 적음
- 운영자가 보호해야 할 플레이어 건축과 자원 월드가 줄어듦

### 3.5 단점

- 마인크래프트의 채굴·건축·농사 경험이 거의 사라짐
- 장기 플레이가 전투, 포획과 반복 대전에 편중될 수 있음
- 필요한 아이템 공급을 상점, 트레이너 보상과 퀘스트로 다시 설계해야 함
- 기존 코블몬 플레이어가 기대하는 자유 샌드박스와 차이가 큼

## 4 2안: 서바이벌 격자 월드

### 4.1 정의

세대 월드를 일반 서바이벌 월드처럼 운영한다. 황혼의 숲 랜드마크와 유사하게 특정한 격자 셀에 마을·체육관을 결정론적으로 생성하지만, 지역은 선형으로 연결하지 않는다.

```text
자유 생성 서바이벌 지형
  ├─ 격자 셀 A: 마을·체육관 후보
  ├─ 격자 셀 B: 랜드마크 후보
  ├─ 격자 셀 C: 마을·체육관 후보
  └─ 플레이어가 원하는 순서로 탐색
```

### 4.2 포함 요소

- 세대별 독립 월드와 세대별 포켓몬 스폰
- 서바이벌 모드의 채광, 건축, 농사, 사냥과 자원 파밍
- 특정 격자 좌표·셀 기반 마을과 체육관 생성
- 바이옴과 지형에 맞춘 구조물 후보 선택
- 비선형 탐색과 자유로운 거점 건축
- 전환 월드, 챔피언로드와 리그

### 4.3 제외 요소

- 순차 지역 1→8 구조
- 바이옴 사이를 격리하는 거대한 벽과 강제 관문
- 비전머신 기반 탑승 제한
- 파도타기 전용 수중 제약
- 별도 PC 서바이벌 월드

### 4.4 장점

- 코블몬과 마인크래프트의 기존 샌드박스 경험을 가장 잘 보존
- 채광, 농사, 건축, 자동화와 탐험 모드를 자연스럽게 결합
- 별도 생존 차원과 PC 이동 시스템이 필요 없음
- 플레이어가 각자 다른 탐험 경로와 거점을 만들 수 있음

### 4.5 단점

- 체육관 순서와 난이도 곡선을 통제하기 어려움
- 비행·수영·굴착으로 모든 지형을 자유롭게 통과하므로 원작식 관문이 약함
- 격자 구조물이 부적절한 바이옴이나 다른 구조물과 충돌할 수 있음
- 마을과 체육관을 찾는 일이 좌표 탐색이나 장거리 이동 노동이 될 수 있음
- 플레이어별 진행 순서가 달라 레벨 스케일링 또는 자유형 관장 규칙이 필요함

## 5 3안: 하이브리드

### 5.1 정의

세대 월드는 본가식 진행 구조를 유지하되 게임 모드는 `SURVIVAL`로 운영한다. 서버 권한이 대부분의 자연환경과 구조물을 보호하고 필드 작물과 특수 던전의 재생 광물만 채집하게 한다. 시작 마을의 자기 집 PC에서는 공유 농장 차원의 개인 1청크 플롯으로 접속한다.

```text
세대 보호형 서바이벌 월드
  → 시작 마을의 집 PC
  → AE2식 가상공간으로 연출된 개인 1청크 농장
  → 귀환
  → 세대 필드 진행
```

### 5.2 포함 요소

- 순차 8지역, 경계, 비전머신과 리그 진행
- 서버 권한 기반 자연환경·구조물 보호
- 필드 지정 작물과 특수 던전 재생 광물 채집
- 집 PC와 가상공간 접속 연출
- 공유 농장 차원의 플레이어별 1청크 플롯
- 세대 월드와 농장 사이의 보호 프로필·가방 포켓 전환
- 규토리·나무열매 재배, 제한된 보관과 소규모 꾸미기

### 5.3 장점

- 포켓몬 본가식 필드 진행과 마인크래프트 생존 활동을 모두 보존 가능
- 세대 월드의 지형·구조물을 플레이어 건축으로부터 보호
- 생존 공간을 개인 기지 또는 가상 시뮬레이션으로 연출 가능
- 생존 콘텐츠를 세대 진행과 분리해 운영·초기화할 수 있음

### 5.4 단점

- 서바이벌 월드에서 무엇을 해야 하는지가 불명확하면 부가 메뉴처럼 느껴짐
- 같은 아이템과 포켓몬을 두 공간에서 공유할 때 경제·진행 우회가 발생
- 차원 이동, 게임 모드, 귀환, 사망, 인벤토리와 백업 관리가 복잡
- 허용 자원과 보호 블록의 구분이 불명확하면 조작이 답답할 수 있음
- 유체·폭발·자동화 등 환경 훼손 우회 방어 범위가 큼
- 두 종류의 콘텐츠를 모두 제작해야 하므로 개발량이 가장 큼

### 5.5 확정된 생존 범위

3안은 자유 서바이벌이 아니라 허용 행동을 명시하는 보호형 서바이벌로 확정한다.

| 항목 | 확정 기준 |
|------|-----------|
| 게임 모드 | 모든 플레이 공간에서 `SURVIVAL` 유지 |
| 일반 필드 | 블록 설치와 자연환경·구조물 변경 금지, 지정 작물만 수확 |
| 특수 던전 | 블록 설치 금지, 자연 동굴 대체, 등록된 재생 광물 노드만 채굴 |
| 개인 공간 | PC 기반 1청크 농장과 소규모 꾸미기 |
| 건축 | 일반 필드 금지, 개인 농장의 허용 블록만 가능 |
| 자동화 | 필드·던전 금지, 농장에서도 고비용 자동화 제한 |
| 허기 | 핵심 진행 시스템으로 사용하지 않음 |
| 아이템 | 본가식 가방 공유, 공간별 허용 포켓·도구 제한 |

### 5.6 보호형 하이브리드의 가치

서바이벌 모드를 유지하면 모드 작물, 곡괭이와 일반 블록 상호작용을 자연스럽게 사용할 수 있다. 동시에 서버 권한으로 일반 필드와 진행 구조물을 보호하면 본가식 동선도 유지할 수 있다.

- 필드의 열매·특수 작물을 직접 수확하는 경험
- 달맞이산 같은 이름 있는 던전이 자연 동굴 탐험을 대체
- 고정 노드를 채굴할 때 같은 자리의 광물 종류가 가중치로 바뀌는 재생 채굴
- 벽을 파거나 블록을 쌓아 관문·퍼즐을 우회하는 행동 차단
- 개인 농장에서만 허용되는 장기 재배와 소규모 꾸미기

자원 채집은 메인 진행의 의무가 아니라 선택형 공급 경로로 둔다. 필수 재료에는 상점·퀘스트·전투 보상 같은 대체 획득처를 제공하고, 자세한 권한과 자원 재생 규칙은 [보호형 서바이벌 필드와 재생 자원](PROTECTED_SURVIVAL_RESOURCES.md)에서 관리한다.

### 5.7 축소형 하이브리드: 1청크 개인 농장

넓은 서바이벌·건축 월드 대신 플레이어마다 1청크 개인 농장만 제공하는 변형이다. PC 접속의 의미를 규토리와 포켓몬 열매 재배로 한정한다.

| 항목 | 축소형 기준안 |
|------|---------------|
| 공간 | 공유 농장 차원의 플레이어별 16×16 플롯 |
| 핵심 활동 | 규토리·열매 심기, 수확과 소규모 꾸미기 |
| 제외 | 채광, 허기, 몬스터 사냥, 대규모 자동화와 자유 월드 탐험 |
| 메인 진행 영향 | 선택형 보조 공급처, 필수 진행 조건으로 사용하지 않음 |
| 운영 이점 | 넓은 월드보다 저장·보호·백업 범위가 작고, 활성 농장당 1청크 상시 로드를 예측 가능하게 운용 가능 |
| 주요 위험 | 플레이어 수에 따른 로드 청크 증가, 고비용 자동화, 부계정 플롯 악용, 1.21.1 오프라인 성장 처리 |

이 변형은 순수 어드벤처의 집중력을 크게 해치지 않으면서 PC와 개인 공간의 의미를 남길 수 있다. 상세 설계는 [PC 기반 1청크 개인 농장](PERSONAL_FARM_PLOT.md)에서 관리한다.

## 6 공통으로 유지되는 설계

세 안 중 무엇을 선택해도 다음은 유지한다.

- 세대별 독립 월드
- 세대별 포켓몬 스폰 프로필
- 세대별 마을·체육관 콘텐츠
- 세대 완료 후 전환 월드의 챔피언로드·리그 이동
- 리그 완료 후 다음 세대 월드 해금
- 플레이어별 배지, 관장과 리그 완료 상태
- 차원 입장 권한, 안전 귀환과 서버 재시작 복구

마을 수가 정확히 8개인지, 관장 순서가 선형인지와 비전머신을 사용하는지는 아키텍처별로 달라진다.

## 8 프로토타입 범위

3안의 핵심 연결을 먼저 검증한다. 1·2안 프로토타입은 3안이 기술적으로 성립하지 않거나 프로젝트 범위가 바뀔 때만 수행한다.

### 8.1 보존 대안: 1안 프로토타입

- 어드벤처 지역 2개, 관문 1개, 체육관 1개
- 공중날기·파도타기 시험 포켓몬
- 블록 편집 없는 60분 플레이

### 8.2 보존 대안: 2안 프로토타입

- 서바이벌 월드의 2×2 랜드마크 격자
- 서로 다른 바이옴의 마을·체육관 2개
- 채광·건축과 자유 탐색을 포함한 60분 플레이

### 8.3 3안 프로토타입

- 보호형 서바이벌 지역 2개, 관문 1개와 체육관 1개
- 수확 작물 1종과 고정형 광물 재추첨 노드가 있는 시험 던전 1개
- 집 PC와 플레이어별 1청크 시험 농장
- 규토리·나무열매 재배, 상시 로드와 오프라인 성장 처리
- 본가식 가방과 농장 허용 포켓 사이의 아이템 이동
- PC 왕복, 게임 모드 복원, 사망·재접속과 서버 재시작 복구

## 9 후속 결정 질문

1. 개인 농장에서 허용할 작물, 장식 블록과 건축 높이는 무엇인가?

3. PC의 AE2식 가상공간 연출을 실제 의존 모드로 구현할 것인가, 자체 연출로 대체할 것인가?
4. 세대 월드와 농장에서 가방의 어떤 포켓과 퀵슬롯을 허용할 것인가?
5. 첫 세대 월드 수직 구간에 포함할 두 지역의 바이옴과 관장은 무엇인가?
