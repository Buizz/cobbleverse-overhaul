# 세대 월드 아키텍처 3안 비교

> 관련 요구사항: F-01, F-07, F-11, F-12
>
> 관련 결정: D-13 세대 월드 아키텍처, D-14 하이브리드 서바이벌 범위
>
> 설계 상태: 3개 후보 보존 / 최종안 미정

## 1 결정 목적

세대별 월드와 세대 사이 전환·리그 월드는 모든 안에 공통으로 유지한다. 결정할 것은 세대 월드에서 마인크래프트 생존 경험과 포켓몬 본가식 진행 중 어느 쪽을 중심에 둘 것인가이다.

```text
모든 안의 공통 구조

1세대 월드
  → 1세대 전환 월드·챔피언로드·리그
  → 2세대 월드
  → 2세대 전환 월드·챔피언로드·리그
  → 다음 세대 ...
```

아래 세 안은 모두 유효한 후보이며 최종 결정 전까지 삭제하지 않는다.

## 3 1안: 어드벤처 월드

### 3.1 정의

세대 월드를 포켓몬 본가의 필드처럼 만든다. 플레이어는 어드벤처 모드로 지역 1부터 8까지 이동하고, 관장·비전머신·리그를 통해 진행한다.

```text
지역 1 → 지역 2 → ... → 지역 8 → 전환 월드·리그
```

### 3.2 포함 요소

- 순차 지역 8개와 지역별 체육관 도시
- 지역마다 설정된 바이옴 풀
- 벽, 산맥, 절벽, 바다와 제한된 관문
- 비전머신 기반 탑승
- 공중날기의 지역 경계 자유 통과
- 파도타기 없이는 건널 수 없는 제한 수역
- 트레이너, 포켓몬 포획, 상점, 관장과 스토리 던전
- 세대별 포켓몬 스폰과 리그 전환 월드

### 3.3 제외 요소

- 집 PC를 통한 별도 서바이벌 월드
- 일반적인 채광, 벌목, 농사와 자유 건축
- 마인크래프트식 생존 사냥과 자원 파밍
- 자동화 설비와 대규모 생산 기지
- 자원 파밍을 목적으로 반복하는 일반 던전 조합

달맞이산처럼 포켓몬 원작의 진행을 재현하는 스토리 던전은 유지할 수 있다. 제외 대상은 마인크래프트 자원 파밍을 위한 던전·채굴 루프다.

### 3.4 장점

- 포켓몬 본가에 가장 가까운 진행과 이동 경험
- 플레이어가 벽을 파거나 쌓아 관문을 우회하지 못함
- 지역, 관장, 비전머신과 포켓몬 출현 레벨을 정교하게 설계 가능
- 건축·자동화 모드로 인한 진행 및 경제 붕괴가 적음
- 운영자가 보호해야 할 플레이어 건축과 자원 월드가 줄어듦

### 3.5 단점

- 마인크래프트의 채굴·건축·농사 경험이 거의 사라짐
- 장기 플레이가 전투, 포획과 반복 대전에 편중될 수 있음
- 필요한 아이템 공급을 상점, 트레이너 보상과 퀘스트로 다시 설계해야 함
- 기존 코블몬 플레이어가 기대하는 자유 샌드박스와 차이가 큼

## 4 2안: 서바이벌 격자 월드

### 4.1 정의

세대 월드를 일반 서바이벌 월드처럼 운영한다. 황혼의 숲 랜드마크와 유사하게 특정한 격자 셀에 마을·체육관을 결정론적으로 생성하지만, 지역은 선형으로 연결하지 않는다.

```text
자유 생성 서바이벌 지형
  ├─ 격자 셀 A: 마을·체육관 후보
  ├─ 격자 셀 B: 랜드마크 후보
  ├─ 격자 셀 C: 마을·체육관 후보
  └─ 플레이어가 원하는 순서로 탐색
```

### 4.2 포함 요소

- 세대별 독립 월드와 세대별 포켓몬 스폰
- 서바이벌 모드의 채광, 건축, 농사, 사냥과 자원 파밍
- 특정 격자 좌표·셀 기반 마을과 체육관 생성
- 바이옴과 지형에 맞춘 구조물 후보 선택
- 비선형 탐색과 자유로운 거점 건축
- 전환 월드, 챔피언로드와 리그

### 4.3 제외 요소

- 순차 지역 1→8 구조
- 바이옴 사이를 격리하는 거대한 벽과 강제 관문
- 비전머신 기반 탑승 제한
- 파도타기 전용 수중 제약
- 별도 PC 서바이벌 월드

### 4.4 장점

- 코블몬과 마인크래프트의 기존 샌드박스 경험을 가장 잘 보존
- 채광, 농사, 건축, 자동화와 탐험 모드를 자연스럽게 결합
- 별도 생존 차원과 PC 이동 시스템이 필요 없음
- 플레이어가 각자 다른 탐험 경로와 거점을 만들 수 있음

### 4.5 단점

- 체육관 순서와 난이도 곡선을 통제하기 어려움
- 비행·수영·굴착으로 모든 지형을 자유롭게 통과하므로 원작식 관문이 약함
- 격자 구조물이 부적절한 바이옴이나 다른 구조물과 충돌할 수 있음
- 마을과 체육관을 찾는 일이 좌표 탐색이나 장거리 이동 노동이 될 수 있음
- 플레이어별 진행 순서가 달라 레벨 스케일링 또는 자유형 관장 규칙이 필요함

## 5 3안: 하이브리드

### 5.1 정의

세대 월드는 1안과 같은 어드벤처 구조로 운영한다. 시작 마을의 자기 집 PC에서 별도의 서바이벌 공간으로 접속해 채집·건축 등 허용된 생존 활동을 한다.

```text
세대 어드벤처 월드
  → 시작 마을의 집 PC
  → 공용·개인·AE2식 가상 서바이벌 공간
  → 귀환
  → 세대 어드벤처 진행
```

### 5.2 포함 요소

- 1안의 순차 8지역, 경계, 비전머신과 리그 진행
- 집 PC와 가상공간 접속 연출
- 별도 서바이벌 공간
- 세대 월드와 생존 공간 사이의 게임 모드 전환
- 공용 대형 월드, 개인 소형 차원 또는 AE2식 공간 후보

### 5.3 장점

- 포켓몬 본가식 필드 진행과 마인크래프트 생존 활동을 모두 보존 가능
- 세대 월드의 지형·구조물을 플레이어 건축으로부터 보호
- 생존 공간을 개인 기지 또는 가상 시뮬레이션으로 연출 가능
- 생존 콘텐츠를 세대 진행과 분리해 운영·초기화할 수 있음

### 5.4 단점

- 서바이벌 월드에서 무엇을 해야 하는지가 불명확하면 부가 메뉴처럼 느껴짐
- 같은 아이템과 포켓몬을 두 공간에서 공유할 때 경제·진행 우회가 발생
- 차원 이동, 게임 모드, 귀환, 사망, 인벤토리와 백업 관리가 복잡
- 어드벤처와 생존 플레이가 서로 단절될 수 있음
- 두 종류의 콘텐츠를 모두 제작해야 하므로 개발량이 가장 큼

### 5.5 반드시 결정할 생존 범위

하이브리드를 선택하려면 아래 항목을 먼저 확정해야 한다.

| 항목 | 선택 예시 |
|------|-----------|
| 건축 | 개인 집만 / 자유 기지 / 공동 도시 |
| 자원 | 바닐라 광물 / 모드 광물 / 제한된 시뮬레이션 자원 |
| 농사 | 식량만 / 경제 작물 / 포켓몬 육성 재료 |
| 자동화 | 금지 / 제한 / 전체 허용 |
| 야생 포켓몬 | 없음 / 공통종 / 세대 진행 연동 |
| 아이템 반입 | 전부 공유 / 태그별 제한 / 별도 인벤토리 |
| 공간 소유 | 서버 공용 / 파티 / 개인 |
| 초기화 | 영구 / 자원 구역만 초기화 / 시뮬레이션 셀 교체 |

생존 공간의 활동이 어드벤처 진행에 필요한 물자를 공급한다면 사실상 강제 콘텐츠가 된다. 반대로 아무 영향이 없다면 사용할 이유가 약해진다. 하이브리드의 핵심 결정은 생존 콘텐츠가 `필수`, `보조`, `장식·창작` 중 어떤 역할인지 정하는 것이다.

### 5.6 현재 전제에서의 하이브리드 가치

현재 고려 중인 전제는 다음과 같다.

- 채광 콘텐츠는 거의 또는 전혀 사용하지 않는다.
- 세대 월드와 별도 공간 모두 허기·식사 관리를 핵심 시스템으로 사용하지 않는다.
- 별도 공간에서 남는 주요 활동은 농사와 건축이다.
- 포켓몬 본가식 진행을 방해하는 자원 파밍은 만들지 않는다.

이 조건에서는 별도 공간이 `서바이벌 월드`로서 제공하는 기능적 목적이 매우 약하다. 식량이 필요하지 않으면 일반 농사는 장식 외의 용도가 없고, 광물을 사용하지 않으면 도구·설비·자동화의 발전 루프도 사라진다. 억지로 포켓몬 육성 재료나 필수 재화를 농사에 연결하면 본가식 모험을 위해 선택한 어드벤처 구조에 다시 생존 반복 작업을 강제하게 된다.

하이브리드를 유지했을 때 남는 실질적인 이득은 스트리머 서버의 **사회·창작 공간**이다.

- 방송 사이의 휴식 시간에 모여 대화하고 공동 작업을 할 장소
- 플레이어별 집, 길드하우스와 서버 공동 도시
- 포획한 포켓몬, 배지, 트로피와 시즌 기록 전시
- 건축 대회, 테마 마을, 사진 촬영과 시청자 참여 이벤트
- 세대 월드를 교체하거나 초기화해도 유지되는 서버의 역사와 정체성
- 전투·진행을 원하지 않는 날에도 접속할 수 있는 낮은 긴장도의 활동

이 목적을 선택한다면 별도 공간을 `서바이벌 월드`가 아니라 `소셜·건축 월드` 또는 `홈 월드`로 정의하는 편이 정확하다. 채광과 허기는 제거하고 건축 재료는 상점, 어드벤처 보상, 정기 지급 또는 건축 전용 카탈로그로 제공할 수 있다.

| 하이브리드 변형 | 목적 | 현재 전제와의 적합성 |
|-----------------|------|----------------------|
| 생존 진행형 | 채광·농사·자동화로 성장 | 낮음 |
| 보조 자원형 | 열매·규토리·장식 재료 생산 | 중간, 반복 작업 강제 위험 |
| 소셜·건축형 | 집, 공동 도시, 전시와 방송 이벤트 | 높음 |
| 목적 없는 자유 월드 | 특별한 보상·행사 없이 별도 공간만 제공 | 매우 낮음 |

따라서 현재 비교해야 할 실질적인 선택지는 `1안 순수 어드벤처`와 `3안 소셜·건축형 하이브리드`다. 소셜·건축 콘텐츠를 지속적으로 운영할 계획이 없다면 PC와 별도 월드는 제거하는 편이 낫다.

### 5.7 축소형 하이브리드: 1청크 개인 농장

넓은 서바이벌·건축 월드 대신 플레이어마다 1청크 개인 농장만 제공하는 변형이다. PC 접속의 의미를 규토리와 포켓몬 열매 재배로 한정한다.

| 항목 | 축소형 기준안 |
|------|---------------|
| 공간 | 공유 농장 차원의 플레이어별 16×16 플롯 |
| 핵심 활동 | 규토리·열매 심기, 수확과 소규모 꾸미기 |
| 제외 | 채광, 허기, 몬스터 사냥, 대규모 자동화와 자유 월드 탐험 |
| 메인 진행 영향 | 선택형 보조 공급처, 필수 진행 조건으로 사용하지 않음 |
| 운영 이점 | 넓은 월드보다 저장·보호·백업 범위가 작고, 활성 농장당 1청크 상시 로드를 예측 가능하게 운용 가능 |
| 주요 위험 | 플레이어 수에 따른 로드 청크 증가, 고비용 자동화, 부계정 플롯 악용, 1.21.1 오프라인 성장 처리 |

이 변형은 순수 어드벤처의 집중력을 크게 해치지 않으면서 PC와 개인 공간의 의미를 남길 수 있다. 상세 설계는 [PC 기반 1청크 개인 농장](PERSONAL_FARM_PLOT.md)에서 관리한다.

## 6 공통으로 유지되는 설계

세 안 중 무엇을 선택해도 다음은 유지한다.

- 세대별 독립 월드
- 세대별 포켓몬 스폰 프로필
- 세대별 마을·체육관 콘텐츠
- 세대 완료 후 전환 월드의 챔피언로드·리그 이동
- 리그 완료 후 다음 세대 월드 해금
- 플레이어별 배지, 관장과 리그 완료 상태
- 차원 입장 권한, 안전 귀환과 서버 재시작 복구

마을 수가 정확히 8개인지, 관장 순서가 선형인지와 비전머신을 사용하는지는 아키텍처별로 달라진다.

## 8 결정 전 프로토타입

세 안을 모두 완성하지 않고 핵심 경험만 비교한다.

### 8.1 1안 프로토타입

- 어드벤처 지역 2개, 관문 1개, 체육관 1개
- 공중날기·파도타기 시험 포켓몬
- 블록 편집 없는 60분 플레이

### 8.2 2안 프로토타입

- 서바이벌 월드의 2×2 랜드마크 격자
- 서로 다른 바이옴의 마을·체육관 2개
- 채광·건축과 자유 탐색을 포함한 60분 플레이

### 8.3 3안 프로토타입

- 1안의 작은 어드벤처 지역
- 집 PC와 하나의 시험 서바이벌 공간
- 생존 공간에서 얻은 자원의 사용처 1개
