# 트레이너 스킨 수동 리터치

## 폴더

- `generated/`: 자동 생성기가 만드는 1차 64×64 스킨입니다. 다시 빌드하면 덮어씁니다.
- `manual/`: 사람이 직접 수정한 64×64 PNG를 저장합니다. 자동 생성기는 이 폴더를 수정하지 않습니다.

## 작업 순서

1. `generated/<트레이너>.png`를 확인합니다.
2. 수정할 파일을 `manual/`에 같은 이름으로 복사합니다.
3. `manual/<트레이너>.png`를 픽셀 편집기로 수정합니다.
4. 콘텐츠 관리자 페이지를 새로고침해 Minecraft 입체 미리보기를 확인합니다.
5. 해당 매니페스트를 다시 실행하면 수동 수정본이 게임 리소스 폴더에 반영됩니다.

수동 수정본은 반드시 64×64 PNG여야 합니다. 자동 생성본을 새로 만들더라도
`manual/`의 파일은 보존되며 미리보기와 최종 출력에서 우선 적용됩니다.
