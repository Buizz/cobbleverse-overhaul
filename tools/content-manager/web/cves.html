    텍스트 적용 시 lexer와 parser를 거쳐 공통 AST를 교체합니다. 문법 오류에는 파일·줄·열이 표시됩니다.

    현재 스크립트에 이벤트 추가

    파일 맨 뒤에 독립적인 발동 이벤트와 기본 페이지를 추가합니다. 기존 이벤트와 명령은 유지되며, CVES 저장 전에는 파일을 변경하지 않습니다.

    말 걸기·퀘스트 이벤트는 파일당 하나입니다. 말 걸기의 상태별 대화는 기존 이벤트에 페이지를 추가하세요. 반복·재사용 대기시간 등은 추가 후 속성에서 설정할 수 있습니다.
