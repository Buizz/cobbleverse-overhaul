# Pretendard webfont

Content Studio bundles `PretendardVariable.woff2` so Korean and Latin UI text
renders consistently without a network connection.

- Font: Pretendard Variable 1.3.9
- Upstream: https://github.com/orioncactus/pretendard
- Source: `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`
- License: SIL Open Font License 1.1 with Reserved Font Name `Pretendard`
- License text: `LICENSE-Pretendard.txt`

Do not remove the license file when redistributing the bundled webfont. If the
font is modified, follow the Reserved Font Name requirements in the license.
