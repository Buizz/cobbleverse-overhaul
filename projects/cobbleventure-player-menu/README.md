# Cobbleventure Player Menu

플레이어 메뉴, 자체 가방과 가방 연동 구매·판매 상점 UI를 제공하는 NeoForge 모드입니다.

인벤토리 키를 Cobbleventure의 본가식 세로 플레이어 메뉴 진입점으로 바꾸는
NeoForge 1.21.1 모드다.

플레이어에게 보이는 음악 재생, 트레이너 배틀 인트로와 마을·도로 진입 안내도
이 모듈이 소유한다. World Bootstrap은 판정한 월드 위치 값만 전달한다.

## 현재 동작

- 바닐라 인벤토리 화면이 열릴 때 화면 오른쪽의 본가식 세로 메뉴로 바꾼다.
- 포켓몬, 가방, 장비, PC, 트레이너 카드, 퀘스트, 지도, 포켓네비와 도감을 고정 순서로 표시한다.
- 마우스, 방향키·Enter와 숫자키 `1`~`9`로 항목을 선택한다.
- 각 메뉴는 기본 단축키(`U/B/G/P/C/J/M/N/K`)로 필드에서 바로 열 수 있으며 Minecraft `설정 → 조작 → Cobbleventure 플레이어 메뉴`에서 변경하거나 해제할 수 있다.
- 플레이어 메뉴의 각 행과 왼쪽 선택 정보에 현재 적용된 단축키를 표시한다.
- 코블몬 요약·파티 화면과 같은 회색 패널, 밝은 선택 슬롯과 얇은 명암 테두리를 사용한다.
- 코블몬이 설치되어 있으면 몬스터볼·PC·도감 등 실제 코블몬 아이템 아이콘을 사용한다.
- 코블몬이 없거나 대응 아이템이 없으면 안전하게 바닐라 아이콘으로 대체한다.
- 왼쪽의 작은 패널에서 트레이너명, 파티 수, 선택 항목 설명과 연결 상태를 보여준다.
- 전체 화면 오버레이와 기본 메뉴 블러를 사용하지 않아 월드를 계속 보여준다.
- 인벤토리 키를 다시 누르거나 `Esc`를 누르면 닫는다.
- 장비 항목은 바닐라 인벤토리 화면으로 연결한다.
- 가방 항목은 상단 포켓 탭·검색·아이콘/목록 보기·상세 화면으로 연결한다.
- 가방은 주 인벤토리 36칸과 서버 확장 가방 4,096칸을 전체·회복·볼·배틀·재료·중요 포켓으로 분류하고 자동 정렬한다.
- 가방의 `사용`은 핫바 구성을 바꾸지 않고 Minecraft의 실제 주 손 사용을 호출한다.
- 아이템 종류를 마인크래프트 핫바와 대응하는 등록 슬롯 1~9에 지정할 수 있다. 각 슬롯의 사용 키는 기본 미지정이며 `설정 → 조작 → Cobbleventure 플레이어 메뉴`에서 설정한다.
- `버리기`에서는 1·10·절반·전부 또는 직접 입력한 수량을 선택해 영구 제거한다.
- 포켓몬 항목은 현재 선택한 파티 포켓몬의 Cobblemon 정보 화면을 연다.
- PC 항목은 서버의 Cobblemon `/pc` 명령을 요청해 원격 PC를 연다.
- 도감 항목은 플레이어 인벤토리에 있는 첫 Cobblemon 도감의 색상을 유지해 기존 도감 화면을 연다.
- 포켓네비 항목은 CobbleNav가 설치된 경우 기본 인벤토리 또는 확장 가방의 실제 포켓네비를 사용해 기존 화면을 연다.
- 원격 PC는 서버에서 `cobblemon.command.pc` 권한이 허용돼 있어야 한다.
- 도감 아이템이 없으면 필요한 아이템을 안내한다.
- 포켓네비 아이템이 없으면 필요한 아이템을 안내한다.
- 지도 항목은 콘텐츠 편집기와 동일한 육각 월드맵을 연다.
- 바이옴 타일을 선택하면 해당 서식의 포켓몬 목록을 표시한다.
- 마을 타일은 방문 여부, 체육관 타입과 특별 건물 정보를 표시한다.
- 한 번 방문한 마을은 지도에서 빠른 이동할 수 있고, 서버 관리자는 모든 타일로 디버그 이동할 수 있다.
- CVES `await map_selection` 요청은 같은 월드맵을 목적지 선택 모드로 열며, 일반
  플레이어는 방문한 마을만, 관리자·creative 플레이어는 모든 마을을 선택할 수 있다.
  선택은 settlement ID만 Adventure에 반환하며 Player Menu가 직접 이동시키지 않는다.
- 트레이너 카드 항목은 본가풍 카드에서 플레이어 외형, ID, 플레이 시간, 스코어와 리그 진행을 보여준다.
- 카드의 지역 수와 지역별 관장·리그 수는 가변 목록으로 처리하며, 확정 전에는 미정 예시 칸만 표시한다.
- `cobbleventure_player_menu:world_map` 지도 아이템을 우클릭해도 같은 화면을 연다.
- 아직 화면이 없는 나머지 항목은 선택 시 준비 중 상태를 표시한다.
- Cobblemon의 기본 스타터 선택 화면과 우측 상단의 `M` 키 스타터 안내 토스트는 표시하지 않는다.
- `/starterroulette` 명령으로 모든 세대의 설정된 스타터가 가로로 흐르는 룰렛을 열고, `멈춤`을 누른 시점의 포켓몬을 지급한다.
- `멈춤`을 누르면 약 1.2초 동안 자연스럽게 감속한 뒤 중앙에 가장 가까운 포켓몬으로 결과를 확정한다.
- GUI 배율이 큰 환경에서도 룰렛, 이름, 상태 문구와 버튼이 화면 안에 들어오도록 화면 높이에 맞춰 모델과 간격을 조절한다.
- 서버가 무작위 순서와 일회성 세션을 만들고 Cobblemon의 기존 스타터 지급 경로를 사용하므로 중복 지급과 목록 밖 포켓몬 지급을 막는다.
- CVES `starter_roulette` 요청은 NPC나 후속 대화 label 대신 opaque callback token을 받아 같은 룰렛을 사용하고, 성공 시 선택한 종 ID를 이벤트 세션으로 반환한다.
- 룰렛 화면을 닫으면 서버에 취소를 알리며, CVES 재상호작용은 접속 종료로 잃은 룰렛 UI 세션을 새로 복구한다.
- CVES `give_item`은 확장 가방과 같은 플레이어 저장 데이터에 operation ID를 기록해 정확히 한 번 지급하며, 성공 시 기존 아이템 획득 오버레이와 효과음을 재사용한다.
- 지급 callback이 유실되거나 서버가 재시작되어도 같은 operation ID 재시도는 아이템을 다시 넣지 않고 저장된 지급 결과만 반환한다. 가방이 부족하면 부분 지급하지 않는다.
- 관리자는 `/starterroulette <player>`로 다른 플레이어의 룰렛을 열 수 있다.
- 콘텐츠의 위치·배틀별 음악 상속 규칙을 해석하고 클라이언트 BGM을 전환한다.
- `/cobbleventure_battle_intro`가 트레이너 배틀 시작을 잠시 지연하고 VS 인트로를 표시한다.
- 마을·도로 진입이 두 번 연속 확인되면 지역 명판을 표시하고 현재 지역 표식을 유지한다.

## 트레이너 카드 뱃지 그래픽

게임에서 사용하는 전역 아틀라스는 `src/main/resources/assets/cobbleventure_player_menu/textures/gui/badges.png`다. 1~6세대는 JcFerggy의 16×16 뱃지 시트, 9세대는 ProfessorMorDBG의 팔데아 뱃지 시트를 사용하며, 상세 크레딧과 사용 기록은 [뱃지 그래픽 출처 및 사용 기록](../../docs/asset-permissions/README.md)에 보존한다.

가라르 10개는 프로젝트 편집본인 `../../tools/content-manager/assets/badges/galar-custom.png`의 5열 × 2행에 관장 순서대로 배치한다. 이 파일을 수정한 뒤 다음 명령으로 아틀라스를 다시 만든다.

```bat
python tools\content-manager\build_badge_atlas.py
```

생성기는 모든 확대·축소에 nearest-neighbour를 사용하며, 각 뱃지의 제작자·원본 URL·추출 좌표는 `../../tools/content-manager/badge-image-sources.json`에 기록한다.

## 빌드

저장소에서 사용하는 공용 Gradle Wrapper로 빌드한다.

```bat
projects\cobbleventure-battle-ai\gradlew.bat ^
  -p projects\cobbleventure-player-menu build
```

빌드가 끝나면 JAR이 다음 개발 팩 경로에 설치된다.

```text
pack/overrides/development-placeholder/mods/
```
