# 오브젝트 참고 이미지 모음

지금까지 요청된 3D 장식 오브젝트의 원본 참고 이미지와 생성형 컨셉 이미지를 모은 자료입니다.
새 모델을 제작할 때는 아래 우선순위를 사용합니다.

1. `original_*` 원본 스프라이트
2. `in_world_reference.png` 또는 `shape_reference_photo_*` 형태 참고 사진
3. `generated_concept.png` 생성형 보조 초안

생성형 컨셉은 원본을 임의로 해석한 부분이 있으므로 최종 형태의 기준으로 사용하지 않습니다.

| 번호 | 오브젝트 | 목표 크기/동작 | 폴더 |
| --- | --- | --- | --- |
| 01 | 포켓몬타워 묘비 | 1블록 장식 | `01_pokemon_tower_grave` |
| 02 | 2칸 진열대 | 가로 2 × 높이 2, 좌우 결합 | `02_double_display_case` |
| 03 | 2칸 유리 진열 판매대 | 가로 2 × 깊이 1, 낮은 유리 상판형 일반 상품 가판대 | `03_double_glass_display_counter` |
| 04 | 로켓단 기지 기계 1 | 가로 1 × 높이 2, 세로형 제어 캐비닛 | `04_rocket_base_machine_1` |
| 05 | 로켓단 기지 기계 2 | 가로 1 × 높이 2, 조작대형 기계 | `05_rocket_base_machine_2` |
| 06 | 로켓단 기지 기계 3 | 가로 2 × 높이 3, 원통 장치와 콘솔 결합 | `06_rocket_base_machine_3` |
| 07 | 오박사 연구소 기계 | 바닥 2 × 2 × 높이 2, 중앙 파란 부분은 곧은 원통 | `07_professor_lab_research_device` |
| 08 | 박사 연구소 연결형 책장 | 1칸 단독 사용 및 가로 자동 연결 | `08_professor_lab_connecting_bookshelf` |
| 09 | 1인용 철제 침대 | 바닥 2 × 3, 철제 프레임과 파란 이불 | `09_large_single_iron_bed` |

## 주의 사항

- `03_double_glass_display_counter`의 실사 사진은 낮은 유리 상판형 구조만 참고합니다.
  아이스크림 판매 냉동고 자체를 제작하는 것이 아닙니다.
- 로켓단 기계 1과 2의 원본은 하나의 결합된 스프라이트에 함께 들어 있습니다.
- 좌우 멀티블록은 중앙에 외곽 프레임이나 옆면을 중복 배치하지 않습니다.
- Blockbench 작업 시 블록 경계를 16단위로 맞추고, 전체 원본은 하나의 `.bbmodel`로 보관합니다.
