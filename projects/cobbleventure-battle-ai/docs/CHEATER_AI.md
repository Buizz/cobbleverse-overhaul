# 치터 AI 동작 계약

## 목적

치터 난이도는 일반 관측 모델에 포함되지 않는 상대의 이번 턴 확정 명령을
설정된 확률로 열람하고, 그 명령에 대응해 행동을 다시 선택한다.

## 선택 순서

1. 양쪽 AI 또는 플레이어가 기본 행동을 먼저 확정한다.
2. 치터 AI는 `cheatProbability`에 따라 시드 기반 발동 판정을 한다.
3. 발동하지 않으면 기존 휴리스틱 행동을 그대로 사용한다.
4. 발동하면 전문가 AI가 예상하던 상대 행동 후보를 확정 명령 하나로
   교체한다.
5. 기존 전문가 휴리스틱으로 기술·교체·기믹을 한 번만 판단한다.

EvE에서는 비교 실험의 의미와 실행 비용을 고려해 한쪽 AI만 치터를 사용할
수 있다. UI에서 반대쪽을 치터로 바꾸면 기존 치터는 전문가 휴리스틱으로
돌아가며, API에 양쪽 치터 설정이 들어오면 검증 오류를 반환한다.

## Cobblemon 인게임 연동 제약

현재 위 선택 순서는 `web-lab` 자체 엔진에서 구현되어 있다. Cobblemon
1.7의 기본 `BattleAI` 계약만으로는 플레이어의 확정 명령을 읽을 수 없다.

기본 엔진의 입력 순서는 다음과 같다.

1. `BattleActor.turn()`이 각 배우에게 `BattleMakeChoicePacket`을 보낸다.
2. `AIBattleActor`는 패킷을 받는 즉시 `BattleAI.choose()`를 동기 호출한다.
3. 플레이어는 이후 클라이언트에서 행동을 고르고 서버에 응답한다.
4. `PokemonBattle.checkForInputDispatch()`는 모든 배우의 응답이 모이면
   양쪽 명령을 Showdown에 함께 전송한다.

따라서 AI가 기본 `choose()`에 진입한 시점에는 플레이어의
`BattleActor.responses`가 아직 비어 있다. 현재 저장소에도 정식
`cobblemon-adapter`가 없으므로 웹 구현만으로 인게임 치터 지원이
완료됐다고 판단하면 안 된다.

실제 인게임에서는 서버 측 조정 계층이 필요하다.

1. 일반 전문가와 치터 미발동 턴은 기존 `BattleAI.choose()` 결과를 그대로
   제출한다.
2. 치터 발동 턴에는 AI 배우의 응답 제출만 보류한다.
3. 플레이어의 `setActionResponses()`가 완료된 직후 확정 응답을
   `OpponentKnowledge`로 변환한다.
4. 전문가 AI를 확정 응답 하나로 한 번 실행한 뒤 AI 응답을 제출한다.
5. 양쪽 응답이 준비되면 기존 `checkForInputDispatch()`가 그대로
   Showdown에 전달한다.

이 조정은 서버에서만 수행해야 하며, 클라이언트에 잠긴 상대 명령을
전송해서는 안 된다. 구현 후보는 전용 Cobblemon 전투 배우 어댑터 또는
`AIBattleActor.onChoiceRequested()`와 플레이어 응답 완료 지점을 연결하는
최소 범위 믹스인이다.

## 정보 범위

치터가 열람할 수 있는 정보:

- 기술 슬롯
- 교체 대상
- 메가진화, Z기술, 다이맥스, 테라스탈이 포함된 확정 명령

치터도 알 수 없는 정보:

- 명중 여부
- 급소 여부
- 피해 난수
- 부가 효과 발동 여부
- 같은 턴을 실행한 뒤의 최종 상태

따라서 치터는 상대 명령에 대응하지만 전투 난수까지 예지하지 않는다.
별도의 후보별 전투 실행이나 난수 표본 시뮬레이션도 수행하지 않는다.

## 설정

`aiProfiles[].difficulty`를 `cheater`로 지정하고
`aiProfiles[].cheatProbability`에 `0~1` 값을 넣는다.
값을 생략하면 `0.5`를 사용한다.

```json
{
  "difficulty": "cheater",
  "strategy": "balanced",
  "cheatProbability": 0.5
}
```

PvE와 EvE 구성 화면에서는 0%부터 100%까지 5% 단위로 설정할 수 있다.
같은 시드와 같은 상태에서는 발동 판정과 선택 결과가 재현된다.

## 진단 로그

발동한 턴의 AI 추적 로그에는 다음 정보를 남긴다.

- 설정 확률과 시드 기반 판정값
- 열람한 상대 명령
- 치터가 확정 명령을 반영해 고른 행동
- 확정 명령만 사용해 계산한 기존 전문가 후보 점수와 이유

`selectionPolicy`는 `cheater-exact-command`로 기록한다.

## 성능

치터는 전문가 AI와 같은 후보 평가를 한 번 수행한다. 차이는 상대 행동을
예측하는 대신 확정된 하나만 입력받는 것이므로 실행 시간도 전문가와
비슷해야 한다.
