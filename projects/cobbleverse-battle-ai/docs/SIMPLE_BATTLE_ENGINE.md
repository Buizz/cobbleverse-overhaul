# Cobbleverse 자체 전투 엔진

## 목적

`web-lab/lib/cobbleverse-battle-engine.mjs`는 Pokémon Showdown,
PokeMathMax, Minecraft와 Cobblemon 런타임을 사용하지 않는 첫 독립 전투
규칙 코어다. 현재 `0.6.0`에서는 단순 데미지 교환을 넘어 기술 효과와
필드 효과를 상태 전이로 처리한다.

## 현재 지원

- 1대1 형식의 파티 전투
- HP와 PP
- 기술 우선도와 스피드 기반 행동 순서
- 고정 시드 동률·명중·피해 난수
- 물리·특수 데미지
- 자속 보정
- 18개 타입 상성
- 명중·회피 랭크와 공격·방어·특수·스피드 랭크
- 급소와 급소 단계
- 화상·마비·수면·독·맹독·얼음 상태
- 상태에 따른 행동 불능, 화상 공격 감소, 마비 스피드 감소
- 화상·독·맹독의 턴 종료 피해
- 쾌청·비·모래바람의 기본 피해 보정과 모래바람 지속 피해
- 일렉트릭·그래스·사이코·미스트필드의 기본 보정·회복·상태 차단
- 트릭룸과 순풍의 행동 순서
- 리플렉터·빛의장막·오로라베일·신비의부적·패스트가드
- 스텔스록·압정·독압정·끈적끈적네트의 교체 진입 효과
- 고정·범위 다중 타격, 스킬링크와 확정 급소
- 타격별 명중 판정과 타격별 위력이 다른 연속기
- 현재 HP·상대 HP·속도·무게·상태·랭크·친밀도 기반 동적 위력
- 현재 턴의 행동 순서·피해 여부·피격 횟수·쓰러진 아군 기반 동적 위력
- 직전 기술의 성공 여부·연속 성공 횟수·남은 PP 기반 동적 위력
- 구르기·아이스볼의 5회 강제 연속 사용, 최초 1회 PP 소비와 중단 규칙
- 웅크리기의 교체 전 지속 상태와 구르기·아이스볼 2배 보정
- 테라버스트의 테라 타입·공격 분류·스텔라 위력과 능력치 하락
- 유대변화 지우개굴닌자의 물수리검 위력 보정
- 동적 위력의 계산값과 적용 사유 이벤트
- 회복기, 흡수기, 반동기
- 기술의 확률형 상태이상·랭크 부가효과
- Leftovers, Black Sludge, Life Orb와 구애 계열의 기본 효과
- 회복·상태이상·랭크 변화·KO 가능성을 함께 평가하는 AI 후보 점수
- 기절과 다음 포켓몬 자동 교체
- 플레이어가 선택하는 일반·강제 교체
- 메가진화·Z파워·다이맥스·테라스탈의 자체 엔진 명령
- 진영별 기믹 예약·소비·거부·반환 상태와 사건 로그
- 메가·다이맥스·테라 선행 발동 후 스피드 행동 순서 재계산
- 다이맥스 3턴 지속과 교체·기절 시 즉시 종료
- 메가스톤·Z크리스탈 소지품 및 선택 기술 호환성 검증
- 일반 다이맥스와 거다이맥스 런타임 상태 분리
- 플레이어 다이맥스 자유 선택과 컴퓨터 엔트리 강제 다이맥스 지시 분리
- 엔트리에 지정된 테라타입 고정 및 임의 타입 변경 차단
- 승패와 최대 턴 제한
- 계산 근거가 포함된 이벤트 타임라인
- JSON 입력을 받는 `/api/native-battles` 웹 API

## 아직 미지원

- 모든 기술·특성·도구의 개별 예외 규칙
- 날씨·필드·벽·설치기의 모든 특성·도구·기술 예외
- 연속기의 타격별 특성·도구·부가효과
- 교체기, 길동무, 앙코르 같은 휘발성 상태
- 더블·트리플 배틀
- 2턴 이상 탐색하는 AI

효과 카탈로그에 없는 기술은 조용히 무시하지 않고
`unsupported_effect` 이벤트를 남긴다. 구현되지 않은 규칙을 정상 적용된
것처럼 보이게 하지 않는 정책은 유지한다.

테스트나 밸런스 검증 시에는 `createSimpleBattle({ strictMoveEffectValidation: true, ... })`를
사용한다. 이 옵션이 켜진 전투는 `unsupported_effect`가 발생하는 즉시
오류를 던져, 미구현 기술 효과를 정상 결과로 오해하지 않게 한다.

## 입력 경계

엔진은 종족 ID를 보고 능력치를 추측하지 않는다. 호출자가 레벨, 타입, 최종
능력치와 기술 데이터를 모두 전달해야 한다. 따라서 이후 Cobblemon 1.8 데이터
어댑터나 웹 카탈로그가 바뀌어도 전투 규칙 코어는 영향을 받지 않는다.

## 개발 우선순위

현재 단계에서는 AI의 강함보다 자체 엔진이 포켓몬 전투를 정확하게 재현하는
것을 우선한다.

- AI는 엔진 검증에 필요한 결정론적 기준 행동, 합법 행동 선택과 판단 로그만
  유지한다.
- 기술 선택 점수, 전략 아키타입, 승률 모델과 다중 턴 탐색은 규칙 구현을
  앞질러 확장하지 않는다.
- 새 규칙은 상태 모델, 이벤트 로그, 단위 테스트와 상호작용 테스트를 함께
  추가한다.
- 구현되지 않은 효과가 포함된 전투는 근사 처리하지 않고
  `unsupported_effect`로 드러낸다.
- 우선 목표는 싱글 배틀에서 실제 엔트리에 사용되는 기술·특성·도구를
  완전하게 실행하는 것이다.
- 구현 현황은 현재 엔트리만이 아니라 고정 Showdown Dex의 전체 고유 기술
  938종을 대상으로 감사하고, 실제 사용 여부를 별도 필드로 구분한다.
