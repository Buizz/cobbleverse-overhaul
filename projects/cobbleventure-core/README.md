# Cobbleventure Core

Minecraft, Fabric 및 Cobblemon API를 참조하지 않는 플랫폼 독립 코어다. 아직 출시되지 않은 게임 연동 버전과 무관하게 콘텐츠 계약, 데이터 검증과 진행 규칙을 개발하는 것을 목적으로 한다.

## 모듈

- `adventure-api`: 지역, 좌표, 경계와 연결의 불변 데이터 모델
- `region-engine`: 지역 JSON 로딩과 단일 지역·지역 집합 의미 검증
- `habitat-engine`: 현재 생성된 월드의 서식지별 출현 후보와 포켓몬별 위치 인덱스

`habitat-engine`의 `HabitatMapQueryService`는 플레이어가 발견한 구역만 노출하고,
선택한 구역의 포켓몬 목록에 Cobblemon 원본 버킷·가중치·레벨·위치 타입을 결합한다.
표시되는 `baseBucketSharePercent`는 날씨·시간과 동적 배율 적용 전 같은 버킷 안의
기본 가중치 비중이며 런타임 어댑터가 계산할 최종 스폰 확률과 구분한다.

게임 연동 모듈은 향후 별도 프로젝트에서 이 코어를 사용한다. 코어는 게임 연동 모듈을 역으로 의존하지 않는다.

## 현재 검증 범위

- `namespace:path` 리소스 ID 형식
- 지원 스키마 버전
- 지역 좌표 범위와 앵커 포함 여부
- 구조물 벽 템플릿 필수 조건
- 관문 ID 중복과 자기 연결
- 같은 차원의 지역 겹침
- 존재하지 않는 연결 대상
- 포켓몬 세대·서식지·기후·시간·희귀도 조건
- 강제 포함·제외 및 현재 월드에 실제 생성된 서식지 위치

## 테스트

저장소에 있는 다른 Gradle Wrapper를 사용해 실행할 수 있다.

```powershell
../cobbleventure-battle-ai/gradlew.bat -p . test
```

정식 게임 연동 전까지 다음 항목도 같은 방식으로 플랫폼 독립 구현한다.

1. 진행 조건 표현식과 배지·지역 해금 상태 전이
2. 차원·입구·귀환점 연결 계약
3. 트레이너, 보상과 스폰 프로필의 공통 ID 참조 검증
4. 콘텐츠 팩 전체의 교차 참조 검사와 마이그레이션
