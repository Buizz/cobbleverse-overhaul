# 가이드 이미지 폴더

사용자 가이드의 `[사진: ...]` 자리에 넣을 화면 캡처를 이 폴더에 저장합니다.

권장 파일 이름은 `탭번호-화면-설명.png` 형식입니다.

```text
01-dashboard-overview.png
02-npc-appearance.png
05-world-map-tools.png
14-build-success.png
```

캡처 전 다음 정보를 가려 주세요.

- Windows 사용자 이름과 개인 폴더 경로
- 토큰, 계정, 서버 주소 등 인증 정보
- 공개하면 안 되는 외부 리소스나 라이선스 정보

PNG를 권장하며, 본문 폭에서 글자가 읽히도록 너무 크게 축소하지 않습니다.
