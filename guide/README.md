# Cobbleventure Content Studio 사용자 가이드

이 문서는 Cobbleventure 프로젝트를 처음 받은 콘텐츠 제작자가 설치부터 데이터 편집, 검증, 개발 팩 빌드까지 따라 할 수 있도록 만든 통합 안내서입니다.

> Content Studio는 인증 기능이 없는 **로컬 제작 도구**입니다. `127.0.0.1`에서만 사용하고 인터넷에 직접 공개하지 마세요.

## 가장 먼저 읽을 문서

1. [시작하기](getting-started.md) — 준비물, 실행, 프로젝트 열기, 종료
2. [전체 작업 흐름](workflow.md) — 어떤 탭을 어떤 순서로 사용하는지
3. [빌드와 배포](build-and-deploy.md) — 검사, 생성, 테스트, CurseForge ZIP 만들기
4. 아래의 탭별 상세 가이드

## 화면 구성

[사진: Content Studio 전체 화면. 왼쪽 사이드바, 상단 현재 프로젝트, 새로고침 버튼, 중앙 작업 영역을 번호로 표시]

- 왼쪽 사이드바: 14개 관리 탭을 이동합니다.
- 상단 `현재 프로젝트`: 편집 대상 프로젝트를 확인하거나 다른 프로젝트를 엽니다.
- 상단 `새로고침`: 디스크에서 데이터를 다시 읽습니다. 저장하지 않은 입력은 잃을 수 있으므로 먼저 저장하세요.
- 중앙 작업 영역: 선택한 탭의 목록, 편집 폼, 검증 결과가 표시됩니다.
- 좌측 하단 서버 상태: 초록색이면 로컬 API에 정상 연결된 상태입니다.

## 공통 편집 원칙

1. 상단에서 올바른 프로젝트가 열렸는지 확인합니다.
2. 목록에서 기존 문서를 선택하거나 `＋`로 새 문서를 만듭니다.
3. ID는 생성 후 바꾸기 어렵습니다. 소문자 영문, 숫자, 밑줄 규칙을 지키고 의미가 분명한 이름을 사용합니다.
4. 입력 후 `문서 검증` 또는 `검증 후 저장`을 누릅니다.
5. 오류가 있으면 원본 파일은 덮어쓰지 않습니다. 화면 하단의 오류를 고친 뒤 다시 저장합니다.
6. 관련 탭 작업이 끝나면 대시보드에서 `전체 검증`을 실행합니다.
7. 큰 작업이 끝나면 `빌드 작업`에서 테스트와 필요한 패키징 작업을 실행합니다.

## 아이콘과 메시지 읽기

- `＋`: 새 항목이나 하위 항목 추가
- `검증 후 저장`: 입력값을 검사하고 오류가 없을 때만 파일 저장
- `문서 검증`: 저장하지 않고 현재 문서의 문제 확인
- `삭제`: 되돌리기 어려운 작업입니다. 참조 중인 항목인지 먼저 전체 검증으로 확인하세요.
- `고급 JSON 편집`: 폼에서 제공하지 않는 세부 값을 편집할 때만 사용합니다. JSON 적용 후 반드시 다시 검증하세요.
- 경고: 당장 저장을 막지는 않지만 배포 전에 확인해야 합니다.
- 오류: 저장 또는 빌드를 막는 문제입니다.
