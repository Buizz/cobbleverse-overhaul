# 전체 작업 흐름

Content Studio의 데이터는 서로 참조합니다. 아래 순서로 만들면 선택 목록이 비어 있거나 참조 오류가 생기는 일을 줄일 수 있습니다.

## 권장 제작 순서

1. **게임 데이터**에서 대화와 관문에 사용할 아이템·진행 변수를 선언합니다.
2. **바이옴 관리**에서 포켓몬 출현 프로필과 바이옴 세트를 준비합니다.
3. **음악 설정**에서 사용 가능한 곡과 기본 BGM을 확인합니다.
4. **배틀 프리셋**에서 적 팀, AI, 규칙과 전투 가방을 만듭니다.
5. **NPC**에서 외형·행동·대화를 만들고 배틀 프리셋을 이벤트에 연결합니다.
6. **리그 관리**에서 관장·사천왕·챔피언 NPC와 배지, 레벨캡을 연결합니다.
7. **NBT 건물 설정**에서 사용할 건물과 NPC 앵커를 확인합니다.
8. **체육관 관리**와 **마을 프리셋**에서 시설과 배치 규칙을 구성합니다.
9. **동굴 관리**에서 내부 공동·통로·입구를 구성합니다.
10. **월드맵**에서 바이옴, 레벨, 길, 마을, 동굴 입구와 관문을 배치합니다.
11. **경제 · 제작**에서 상점, 포켓몬 드롭과 NPC 제작법을 구성합니다.
12. **대시보드**에서 전체 검증을 실행합니다.
13. **빌드 작업**에서 생성·테스트·개발 팩 빌드를 실행합니다.

## 가장 흔한 연결 관계

| 만드는 항목 | 먼저 필요한 항목 | 나중에 사용하는 곳 |
|---|---|---|
| 진행 변수·아이템 선언 | 없음 | NPC 이벤트, 관문 조건, 제작 해금 |
| 배틀 프리셋 | 음악 트랙(선택) | NPC 이벤트, 리그 전투 |
| NPC | 배틀 프리셋, 게임 데이터 | 마을, 체육관, 월드 관문, 리그 |
| 바이옴 프로필 | 포켓몬 서식지 카탈로그 | 바이옴 세트, 월드맵, 동굴 |
| 마을 프리셋 | 체육관, NBT, NPC | 월드맵 배치 |
| 동굴 | 바이옴, NPC | 월드맵의 동굴 입구 |
| 경제 데이터 | NPC, 게임 아이템, 드롭 아이템 | 상점과 NPC 제작 |

## 작은 변경의 완료 기준

- 해당 문서가 `검증 후 저장`에 성공했습니다.
- 대시보드 전체 검증에서 새 오류가 없습니다.
- 참조 대상과 참조하는 문서를 둘 다 확인했습니다.
- 게임용 데이터가 필요한 변경이면 `generate` 또는 관련 빌드를 다시 실행했습니다.
