# 시작하기

## 1. 준비물

Windows 10/11 환경을 기준으로 합니다.

| 프로그램 | 최소 기준 | 확인 명령 |
|---|---:|---|
| Python | 3.10 이상 | `py -3 --version` |
| Java JDK | 21 | `java -version` |
| Node.js | 22.13.0 이상 | `node --version` |
| npm | Node.js에 포함 | `npm --version` |
| PowerShell 또는 명령 프롬프트 | Windows 기본 제공 | 별도 확인 불필요 |

Content Studio 자체는 Python 표준 라이브러리만 사용합니다. Java와 Node.js는 전체 테스트, NeoForge 모드, 전투 Web Lab을 빌드할 때 필요합니다.

## 2. 저장소 준비

프로젝트 ZIP을 받았다면 쓰기 가능한 폴더에 압축을 풉니다. Git으로 받았다면 저장소 루트에 `build.bat`, `content-projects`, `tools` 폴더가 보이는지 확인합니다.

[사진: 파일 탐색기에서 저장소 루트의 build.bat, content-projects, tools 폴더가 보이는 화면]

이후 명령은 저장소 루트에서 실행합니다.

```powershell
cd "프로젝트를 받은 폴더\cobbleverse-overhaul"
```

## 3. 첫 검증

```bat
build.bat validate
```

현재 의존성 Lock이 개발 상태라면 `draft` 경고가 표시될 수 있습니다. `검증 성공: 오류 0개`가 나오면 편집을 시작할 수 있습니다. 오류가 나오면 파일 경로와 메시지를 기록한 뒤 먼저 해결하세요.

## 4. Content Studio 실행

```bat
build.bat web
```

터미널에 Content Manager 시작 메시지가 표시되면 브라우저에서 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)을 엽니다.

[사진: build.bat web 실행 후 서버 주소가 표시된 터미널]

서버 상태만 확인하려면 [http://127.0.0.1:8765/health](http://127.0.0.1:8765/health)을 엽니다. 포트 `8765`를 다른 프로그램이 사용 중이면 해당 프로그램을 종료하거나 다음처럼 다른 포트로 직접 실행합니다.

```powershell
py -3 tools\content-manager\content_manager.py api --root . --port 8766
```

이 경우 브라우저 주소도 `http://127.0.0.1:8766/`으로 바뀝니다.

## 5. 프로젝트 확인과 변경

처음 실행하면 Git에 포함된 `content-projects/cobbleventure-main` 프로젝트가 자동으로 열립니다.

다른 프로젝트를 열려면 다음 순서로 진행합니다.

1. 상단 `현재 프로젝트`를 누릅니다.
2. `폴더 선택` 또는 경로 입력으로 프로젝트 폴더를 지정합니다.
3. 폴더 안에 `project.json`과 `content` 폴더가 있는지 확인합니다.
4. `프로젝트 불러오기`를 누릅니다.
5. 상단의 프로젝트 이름과 경로가 바뀌었는지 확인합니다.

[사진: 현재 프로젝트 버튼과 프로젝트 불러오기 창]

프로젝트를 바꾸면 이후 저장은 새 프로젝트의 파일을 직접 수정합니다. 작업 전 경로를 반드시 확인하세요.

## 6. 안전하게 종료하기

`build.bat web`을 실행한 터미널에서 `Ctrl+C`를 누릅니다. 브라우저 탭만 닫으면 서버 프로세스가 계속 실행될 수 있습니다.

## 자주 발생하는 문제

### 페이지가 열리지 않음

- 서버 터미널이 계속 실행 중인지 확인합니다.
- 주소가 `https`가 아닌 `http://127.0.0.1:8765`인지 확인합니다.
- `/health` 주소가 열리는지 확인합니다.
- `build.bat web`을 다시 실행하면 같은 저장소의 이전 Content Manager 프로세스를 정리하고 재시작합니다.

### 저장 버튼이 비활성화됨

- 왼쪽 목록에서 편집할 문서를 먼저 선택합니다.
- 필수 입력값이나 프로젝트 로딩이 끝났는지 확인합니다.

### 저장 후 내용이 사라짐

- 오류 때문에 저장이 거부됐는지 화면 하단 메시지를 확인합니다.
- `새로고침`을 누르기 전에 저장했는지 확인합니다.
- 현재 프로젝트 경로가 예상한 폴더인지 확인합니다.

### 외부 PC에서 접속하고 싶음

지원하지 않습니다. 이 도구에는 사용자 인증이 없고 로컬 파일을 수정하므로 `127.0.0.1` 외부에 공개하면 안 됩니다.
