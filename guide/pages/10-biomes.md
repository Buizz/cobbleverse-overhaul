# 10. 바이옴 관리

바이옴 관리에서는 포켓몬 출현 조건을 프로필로 만들고, 여러 프로필을 바이옴 세트로 조합하며, 전체 포켓몬 서식지 카탈로그를 검색합니다.

[사진: 바이옴 관리 화면의 프로필/바이옴 세트 테스트/전체 포켓몬 탭]

## 프로필

프로필은 다음 조건을 조합합니다.

- 한국어 이름과 대표 서식지
- 지역도감 시리즈와 최초 등장 세대
- 서식지 번호
- 온도, 습도, 날씨, 시간
- 허용 레어도
- 강제 포함 및 제외 포켓몬
- 보조 서식지 포함 여부

`현재 조건 테스트`를 눌러 예상 출현 목록을 확인한 뒤 저장합니다. 강제 포함은 일반 조건과 무관하게 넣어야 하는 예외에만 사용하고, 제외 목록과 동시에 지정하지 마세요.

## 바이옴 세트 테스트

하나의 실제 바이옴에 여러 프로필과 가중치를 조합할 때 사용합니다.

1. 바이옴 세트를 선택합니다.
2. 포함할 프로필과 가중치를 확인합니다.
3. 모든 조건을 무시할 포켓몬이 있다면 ID를 쉼표로 입력합니다.
4. `세트 테스트`를 누릅니다.
5. 결과의 다양성, 세대와 레어도 분포를 확인합니다.

[사진: 바이옴 세트 가중치와 테스트 결과]

## 전체 포켓몬

한국어 이름 또는 영문 ID로 1,025마리 카탈로그를 검색하고 세대·서식지 필터로 좁힙니다. 특정 포켓몬이 예상 프로필에 나오지 않을 때 원본 서식지 분류를 확인하는 용도입니다.

## 월드와 동굴에서 사용

완성한 바이옴은 [월드맵](05-world-map.md)의 바이옴 브러시와 마을 배치, [동굴 관리](06-caves.md)의 내부 바이옴에서 사용합니다. 월드맵 기후 오버라이드는 프로필 조건 결과를 바꿀 수 있으므로 최종 포켓몬 출현 지도를 함께 확인하세요.

## 저장 전 체크리스트

- [ ] 프로필 ID와 이름이 역할을 설명함
- [ ] 시리즈·세대 조건이 서로 모순되지 않음
- [ ] 강제 포함과 제외 목록 중복 없음
- [ ] 테스트 결과가 비어 있지 않음
- [ ] 희귀 포켓몬이 과도하게 자주 나오지 않음
- [ ] 바이옴 세트 가중치가 의도한 비율임
- [ ] `바이옴 저장`과 전체 검증 성공
