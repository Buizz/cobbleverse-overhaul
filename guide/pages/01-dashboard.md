# 01. 대시보드

대시보드는 현재 프로젝트의 콘텐츠 수와 전체 검증 상태를 가장 먼저 확인하는 화면입니다.

[사진: 대시보드 전체 화면. 프로젝트 이름, 통계 카드, 전체 검증 버튼, 결과 영역 표시]

## 화면 읽기

- `DATA STATUS`: 프로젝트 검증 상태를 요약합니다.
- `NPC`: 대화와 이벤트를 가진 NPC 문서 수입니다.
- `SETTLEMENTS`: 마을 프리셋 수입니다.
- `VALIDATION`: 최근 검증에서 발견한 오류·경고 요약입니다.
- `최근 검증 결과`: 파일별 문제와 설명을 표시합니다.

## 전체 검증 사용법

1. 상단의 현재 프로젝트가 맞는지 확인합니다.
2. `전체 검증`을 누릅니다.
3. 검사가 끝날 때까지 다른 저장 작업을 잠시 멈춥니다.
4. 오류가 있으면 표시된 파일 경로와 메시지에 따라 해당 탭에서 수정합니다.
5. 수정 후 다시 전체 검증을 실행합니다.

`draft` 의존성 경고는 개발 단계에서 허용될 수 있지만, 정식 팩을 만들기 전에는 해결해야 합니다. 오류가 0개라고 해서 인게임 동작까지 보장되는 것은 아니므로 빌드 테스트와 실제 게임 확인도 필요합니다.

## 언제 확인하나요?

- 작업을 시작할 때
- 여러 문서의 참조를 바꾼 뒤
- 항목을 삭제한 뒤
- Git 병합이나 외부 파일 수정 후
- 개발 팩 빌드 직전

## 문제 해결

- 숫자가 `—`로 남음: 서버 연결과 현재 프로젝트 경로를 확인하고 `새로고침`을 누릅니다.
- 검증이 오래 걸림: 중복으로 누르지 말고 완료 메시지를 기다립니다.
- 오류 위치를 모르겠음: 메시지에 나온 상대 경로의 종류를 확인해 대응하는 탭으로 이동합니다.
