# 11. 게임 데이터

게임 데이터 탭은 NPC 대화, 관문, 진행 시스템에서 공통으로 참조할 아이템과 진행 변수 ID를 선언하는 등록부입니다.

[사진: 게임 데이터 탭. 아이템 목록, 진행 변수 목록과 요약 카드 표시]

## 추가 아이템

기반 Minecraft/모드 아이템 ID와 프로젝트에서 사용할 선언 ID, 표시 이름을 연결합니다. 선언된 ID는 NPC 이벤트의 아이템 보유 조건과 보상 선택지에서 재사용할 수 있습니다. 목록과 안내 UI에 다른 외형을 쓰려면 `표시 아이콘 아이템`에 해당 Minecraft/모드 아이템 ID를 입력합니다. 비워 두면 기반 아이템의 아이콘을 사용합니다.

예를 들어 관문 티켓이나 퀘스트 전용 열쇠처럼 여러 이벤트가 같은 물건을 가리킬 때 먼저 등록합니다.

## 진행 변수

진행 상태는 범위와 타입, 기본값을 정합니다.

- 전역: 월드 전체가 공유하는 상태
- 플레이어: 플레이어마다 따로 저장하는 상태
- boolean: 완료/미완료 같은 참·거짓
- integer: 배지 수, 점수, 단계 같은 숫자
- string: 선택한 분기나 상태 이름 같은 문자열

개인 퀘스트 완료 여부를 전역으로 만들면 한 플레이어의 진행이 모두에게 적용될 수 있으므로 범위를 신중히 고르세요.

## 권장 이름 규칙

기능과 범위를 알 수 있게 일관된 접두어를 사용합니다.

```text
quest_route_01_complete
badge_count
story_generation_1_stage
```

이미 NPC·월드맵이 참조하는 ID의 이름을 바꾸면 모든 참조를 함께 수정해야 합니다.

## 저장 전 체크리스트

- [ ] 선언 ID 중복 없음
- [ ] 실제 기반 아이템 ID 존재
- [ ] 표시 아이콘 아이템 ID가 실제로 존재하거나 비어 있음
- [ ] 변수 범위가 멀티플레이 의도와 일치
- [ ] 기본값 타입이 변수 타입과 일치
- [ ] 삭제·이름 변경 전 사용처 확인
- [ ] `검증 후 저장` 후 대시보드 전체 검증 성공
