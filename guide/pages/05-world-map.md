# 05. 월드맵

월드맵은 세대별 육각 타일 지도에서 바이옴, 평균 레벨, 길, 마을, 동굴 입구와 관문을 배치하는 화면입니다. 여러 카탈로그를 조합하는 최종 설계 화면이므로 관련 데이터를 먼저 준비하세요.

[사진: 월드맵 전체 화면. 세대 탭, 도구 레일, 육각 지도, 타일 속성 패널 표시]

## 기본 조작

- 세대 탭: 편집할 세대 월드를 선택
- `＋ 세대 추가`: 새 월드 생성
- 드래그: 지도 이동
- 확대/축소: 도구 레일의 `＋`, `－`
- 전체 맞춤: `⊙`
- `월드 저장`: 현재 세대 지도 저장
- `월드 삭제`: 현재 세대 지도 삭제

저장 상태 문구를 확인하고 탭을 이동하세요.

## 도구별 사용법

### 선택(V)

타일이나 배치물을 눌러 오른쪽 속성을 편집합니다. 마을은 선택 후 드래그해 이동할 수 있습니다.

### 바이옴(B)

프로필과 브러시 반경을 고른 뒤 드래그해 칠합니다. 기존 길은 유지됩니다. 먼저 [바이옴 관리](10-biomes.md)에서 프로필을 준비하세요.

### 지형(T)

높은 숲, 바다, 사막, 돌산, 눈산 같은 접근 불가 배경을 칠합니다. 마을과 길은 건드리지 않습니다.

### 기후(C)

온도, 습도, 날씨를 좌표별로 덮어씁니다. 세 값을 모두 `바이옴 기본값`으로 두면 오버라이드가 제거됩니다.

### 레벨(L)

지역 평균 레벨을 1~100으로 칠합니다. 실제 야생 포켓몬은 평균 ±2 범위로 출현하므로 리그 레벨캡과 함께 점검하세요.

### 길(R)

1. 도로, 자연 통로, 수로 중 표면을 선택합니다.
2. 통로 폭을 정합니다.
3. 마을이나 지형을 차례로 눌러 앵커를 만듭니다.
4. 경로를 확인하고 `길 완료`를 누릅니다.

잘못 찍은 마지막 앵커는 되돌릴 수 있고 전체 초안은 취소할 수 있습니다.

### 마을(S)

마을 프리셋과 이 월드 배치에 적용할 바이옴을 선택한 뒤 타일을 누릅니다. 마을 바이옴은 프리셋이 아닌 **현재 월드맵 배치**에 저장됩니다.

### 동굴(D)

동굴과 내부 입구, 방향, 입구 구조물을 선택합니다. 필요하면 인접 포켓몬센터 구조물과 오프셋도 정합니다. 입구를 놓은 뒤 길 도구로 입구 좌표까지 연결해야 저장할 수 있습니다.

### 오브젝트(O)

관문 또는 빌런기지를 배치합니다. 관문은 실제 건물, NPC 전용, 시스템 차단 방식 중 선택할 수 있습니다. NBT, 방향, 주변 벽·나무·배리어, NPC와 통과 조건을 설정합니다.

통과 조건은 한 줄에 하나씩 입력합니다. 예:

```text
variable|scoreboard|badge_count|>=|2
item|minecraft:ticket|1
pokemon|cobblemon:snorlax
```

조건 조합이 `모든 조건`인지 `하나 이상`인지 반드시 확인하세요.

### 지우개(E)

선택한 지도 요소를 제거합니다. 참조가 있는 마을·동굴·관문을 지운 뒤에는 전체 검증을 실행하세요.

## 권장 지도 제작 순서

1. 접근 불가 배경 지형으로 대륙 형태 구성
2. 바이옴과 기후 칠하기
3. 지역 평균 레벨 구간 설정
4. 마을과 주요 오브젝트 배치
5. 마을 사이 길 연결
6. 동굴 입구 배치 후 길 연결
7. 관문 조건과 차단 메시지 설정
8. 포켓몬 출현 지도 확인
9. 월드 저장 후 전체 검증

## 저장 전 체크리스트

- [ ] 모든 마을과 동굴 입구에 접근 가능한 길 존재
- [ ] 동굴 내부 입구를 중복 배치하지 않음
- [ ] 시작 지역 레벨과 후반 지역 레벨이 의도대로 증가
- [ ] 관문 조건 ID가 게임 데이터/NPC에 존재
- [ ] 수로와 필드 이동 요구 조건이 진행 순서와 일치
- [ ] 포켓몬 출현 미리보기에 빈 핵심 지역 없음
