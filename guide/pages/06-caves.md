# 06. 동굴 관리

동굴 관리에서는 하나의 동굴에 들어갈 공동, 입출구, 통로, 자연 생성 규칙, 트레이너와 내부 바이옴을 구성합니다.

[사진: 동굴 관리 전체 화면. 기본 설정과 3D 배치 편집기 표시]

## 새 동굴 만들기

1. 왼쪽 `＋`를 누릅니다.
2. 파일 ID와 이름을 입력합니다. 현재 월드 세대의 동굴 폴더가 자동으로 사용됩니다.
3. 화면 위쪽의 자동 빌드 영역을 확인합니다. 영역은 입구와 공동의 실제 배치 및 통로 여백을 포함해 16블록 단위로 자동 계산됩니다.
4. 3D 배치 편집기에서 공동과 입구를 만들고 길로 연결합니다.
5. 트레이너와 내부 바이옴을 설정합니다.
6. `문서 검증` 후 `동굴 저장`을 누릅니다.

## 3D 배치 편집기

- `＋ 공동`: 일반 공동, 대공동, 교차점, 랜드마크 공동 추가
- `＋ 입구`: 월드맵에 연결할 입출구 추가
- `↗ 길`: 두 지점을 선택해 통로 생성
- `3D`, `XY`, `XZ`, `ZY`: 시점 전환
- `시점 초기화`: 카메라 위치 복구
- `다른 배치`: 생성 규칙으로 새 배치 계산

[사진: 동굴 3D 편집기에서 공동·입구·통로가 연결된 모습]

요소를 선택하면 오른쪽 속성 패널에서 좌표와 크기를 편집합니다. 공동은 X/Z 반경과 높이, 입구는 표시 이름·진행 조건·안전 좌표, 통로는 너비와 일반/계단/돌다리 종류를 지정합니다.

`다른 배치`를 누르기 전 현재 수동 배치가 보존되는지 저장 상태를 확인하세요.

## 자연 생성과 내부 콘텐츠

자연 동굴 생성에서는 방과 가지 수, 높낮이, 표면 형태를 조절합니다. 입구 사이의 필수 경로는 항상 이어져야 합니다.

트레이너 설정에서는 최대 활성 수, 클래스 풀과 고정 배치를 관리합니다. 내부 바이옴은 실제 인게임 바이옴과 포켓몬 출현 조건에 사용됩니다.

## 월드맵 연결

동굴의 입구를 먼저 만든 후 [월드맵](05-world-map.md)의 동굴 도구에서 각각 배치합니다. 같은 내부 입구는 한 월드에 중복 배치할 수 없습니다. 배치한 입구까지 길을 연결해야 월드 저장 검증을 통과할 수 있습니다.

## 저장 전 체크리스트

- [ ] 모든 입구가 최소 하나의 공동과 연결
- [ ] 고립된 공동이나 끊긴 통로 없음
- [ ] 안전 좌표가 벽이나 낙하 지점이 아님
- [ ] 통로 너비와 높이가 플레이어 이동에 충분
- [ ] 내부 바이옴 ID 존재
- [ ] 고정 트레이너와 클래스 참조 유효
- [ ] `문서 검증`과 전체 검증 성공
