# 07. 마을 프리셋

마을 프리셋은 월드맵에 배치할 마을의 형태, 도로, 주택, 필수 시설과 NPC 배치 규칙을 정의합니다.

[사진: 마을 프리셋 전체 화면. 목록, 마을 형태, 생성 테스트, 시설 설정 표시]

## 새 프리셋 만들기

1. 왼쪽 `＋`를 누릅니다.
2. 파일 ID, 마을 이름과 세대를 입력합니다.
3. 지역·차원·중심·경계 같은 기본값을 채웁니다.
4. 마을 형태와 도로, 주택 팔레트를 설정합니다.
5. 포켓몬센터, 상업 시설, 체육관과 기타 필수 시설을 선택합니다.
6. 배치할 트레이너를 추가합니다.
7. 생성 테스트로 결과를 확인하고 저장합니다.

## 마을 형태와 도로

분기형, 선형, 방사형, 고리형, 계단형 중 지형에 맞는 형태를 사용합니다. 시설 연결 도로 폭과 노면도 함께 정합니다. 표시되는 `16×16`은 블록 수가 아니라 부지 단위라는 점에 주의하세요.

커스텀 마을은 육각 지도에서 점유 타일과 외부 월드 도로가 접속할 출구를 직접 지정합니다. 내부 건물과 도로는 자동 생성됩니다.

[사진: 커스텀 마을 점유 타일과 외부 출구 편집 화면]

## 마을 생성 테스트

시드와 도로 확장 깊이를 바꿔 실제 생성기가 사용할 도로·시설·기본 건물 배치를 미리 봅니다. 같은 시드는 같은 결과를 재현하는 데 사용합니다. `다시 생성` 후 시설이 겹치거나 길에서 단절되지 않았는지 확인하세요.

## 주택과 시설

주택은 기본 골격, 지붕 형태, 지붕 색상 그룹에서 각각 하나 이상 선택해야 합니다.

필수 시설은 체크한 수량만큼 생성됩니다. 포켓몬상점과 백화점은 둘 중 하나만 선택할 수 있습니다. 시작 마을은 포켓몬센터와 상업 시설이 자동 비활성화될 수 있습니다.

체육관을 배치할 때는 종류만 선택합니다. 관장과 내부 트레이너는 [체육관 관리](08-gyms.md)에서 전역으로 지정합니다.

## 트레이너 배치

`트레이너 배치 추가`로 NPC, 프로필, 좌표와 회전을 설정합니다. 싱글배틀은 EasyNPC 1명, 2인 더블배틀은 같은 전투에 참여할 EasyNPC 2명을 배치합니다.

NPC가 마을에 들어가기 전에 [NPC 탭](02-npc.md)에서 외형과 이벤트, 연결 배틀을 완성하세요.

## 저장 전 체크리스트

- [ ] 주택 팔레트 각 그룹에서 하나 이상 선택
- [ ] 시작 마을 시설 제한 확인
- [ ] 포켓몬상점과 백화점 동시 선택 안 함
- [ ] 체육관 ID와 필수 시설 NBT 존재
- [ ] NPC 좌표가 건물 블록 내부나 도로 중앙과 충돌하지 않음
- [ ] 더블배틀 NPC가 2명 모두 배치됨
- [ ] 생성 테스트를 여러 시드로 확인
- [ ] `문서 검증`과 저장 성공
