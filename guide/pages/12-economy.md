# 12. 경제 · 제작

경제 · 제작 탭에서는 상인과 백화점, 포켓몬 처치 드롭, 특수 NPC 제작 의뢰를 한 카탈로그에서 관리합니다. 바닐라 조합은 비활성화 고정이며 NPC 제작 재료는 등록된 포켓몬 드롭 아이템만 사용할 수 있습니다.

[사진: 경제 · 제작 전체 화면과 4개 하위 탭]

## 상인 · 판매 상품

1. `＋`로 상인을 추가합니다.
2. 상인 ID와 이름, 연결 NPC·마을 조건을 설정합니다.
3. 판매 상품, 가격, 수량과 해금 조건을 추가합니다.
4. 검색으로 상인 이름과 상품을 다시 확인합니다.

같은 상품이 여러 상인에게 있을 때 가격 차이가 의도된 것인지 확인하세요.

## 백화점 설정

백화점을 먼저 만들고 층·매장별 카탈로그와 상인을 연결합니다. [마을 프리셋](07-settlements.md)에서 상업 시설을 백화점으로 선택한 마을과 연결 관계를 확인합니다.

## 포켓몬 드롭

1,025종을 개별 편집하지 않고 타입, 세대, 폼, 라벨, 알그룹, 크기 조건으로 대량 규칙을 만듭니다.

1. `＋ 대량 루트 규칙`을 누릅니다.
2. 적용 조건과 드롭 아이템·확률·수량을 입력합니다.
3. 포켓몬 검색과 타입·세대 필터로 적용 결과를 미리 봅니다.
4. 꼭 필요한 종만 개별 재정의합니다.

[사진: 대량 루트 규칙과 특정 포켓몬 적용 결과 미리보기]

넓은 조건의 규칙을 추가하면 예상보다 많은 종에 적용될 수 있습니다. 대표 포켓몬뿐 아니라 조건 경계의 종도 검사하세요.

## NPC 제작법

특수 NPC가 재료를 받고 완제품을 주는 의뢰를 설정합니다. 입력 재료는 포켓몬 드롭 목록에 등록된 아이템만 사용할 수 있습니다. 제작 NPC, 필요 재료·수량, 결과물과 해금 조건을 구성합니다.

## 저장 전 체크리스트

- [ ] 판매 NPC와 마을 참조 존재
- [ ] 가격이 0 또는 음수로 잘못 설정되지 않음
- [ ] 백화점 카탈로그와 마을 시설 연결
- [ ] 드롭 규칙이 너무 넓게 적용되지 않음
- [ ] 드롭 확률·수량 밸런스 확인
- [ ] 모든 제작 재료가 드롭 목록에 존재
- [ ] 제작 해금 변수 존재
- [ ] `검증 후 저장`과 전체 검증 성공
