# 09. NBT 건물 설정

NBT 건물 설정에서는 저장소의 건물 NBT를 검색하고 3D로 확인하며, 내부공간·문 이동·NPC 앵커와 시민 수용 여부를 전역 설정합니다.

[사진: NBT 건물 설정 전체 화면. 구조물 목록, 3D 모델, 오른쪽 설정 패널 표시]

## 건물 찾기와 미리보기

1. `NBT 목록 갱신`으로 디스크의 최신 NBT를 읽습니다.
2. 이름 검색과 구조물 종류 필터로 건물을 찾습니다.
3. 왼쪽 목록에서 건물을 선택합니다.
4. 중앙 3D 모델을 드래그해 회전하고 휠로 확대·축소합니다.
5. NPC 마커 수와 위치를 확인합니다.

구조물 종류는 일반 건물, 주택, 체육관 외관·내부, 일반 내부, 리그, 임시·특수 건물로 나뉩니다.

## 공용 내부공간 만들기

건물 종류와 무관하게 재사용할 빈 내부 NBT를 만들 수 있습니다.

1. 소문자·숫자·밑줄로 공간 키를 입력합니다.
2. 너비, 깊이, 층 높이와 층수를 정합니다.
3. `빈 내부 NBT 만들기`를 누릅니다.
4. [빌드 작업](14-builds.md)의 독립 건축 월드를 빌드합니다.
5. 게임 에딧 월드에서 내부를 건축하고 내보냅니다.
6. `게임 NBT 자동 가져오기`로 저장소에 반영합니다.

[사진: 공용 내부공간 NBT 생성 폼]

## 건물별 설정

- 사용할 내부공간: 공용 내부 NBT를 공간 키로 연결
- 문 이동 설정: NBT의 문 이름을 도착 지점과 연결
- NPC 배정: 외부·내부 NPC 라벨에 전역 NPC 연결
- 시민 수용: 자동 시민 배치가 가능한 건물인지 지정

NPC 마커가 화면에 없다면 NBT에 올바른 라벨이 있는지 먼저 확인하세요.
