# 04. 리그 관리

리그 관리에서는 세대별 체육관 관장, 사천왕, 챔피언의 표시 순서와 레벨캡, NPC, 배지 정보를 연결합니다.

[사진: 리그 관리 탭. 왼쪽 리그 목록과 오른쪽 트레이너/배지 설정]

## 항목 만들기

1. 왼쪽 `＋`를 누릅니다.
2. 리그 항목 ID를 입력합니다. 예: `cobbleventure:league/generation_1/leader_1`.
3. 역할을 관장, 사천왕, 챔피언 중에서 고릅니다.
4. 한국어·영문 이름, 세대, 표시 순서와 지역 ID를 입력합니다.
5. 해당 시점의 레벨캡을 정합니다.
6. 사용할 NPC 엔트리를 선택합니다.
7. 관장이라면 배지 정보와 트레이너카드 표시 여부를 설정합니다.
8. `리그 설정 저장`을 누릅니다.

## NPC 연결

선택한 NPC에 연결된 배틀 프리셋과 팀이 실제 리그 전투에 사용됩니다. `트레이너풀에서 편집`으로 NPC 탭에 이동해 대화와 배틀 연결을 확인할 수 있습니다.

## 레벨캡과 순서

표시 순서는 같은 세대 안에서 중복되지 않게 정하고, 레벨캡은 진행할수록 내려가지 않도록 구성하는 것이 일반적입니다. 분기형 진행이라면 같은 단계의 항목에 동일하거나 유사한 캡을 적용하고 실제 플레이 난이도를 시험하세요.

## 배지 설정

배지 아이템 목록에는 CobbleverseBadges에서 확인된 실제 항목을 사용합니다. 한국어·영문 배지 이름과 트레이너카드 표시 여부를 함께 지정합니다. NPC 이벤트의 체육관 관장 프리셋에서도 같은 배지를 지급하는지 확인하세요.

## 저장 전 체크리스트

- [ ] 지역 ID와 세대 일치
- [ ] 표시 순서 중복 없음
- [ ] 레벨캡 진행 순서 자연스러움
- [ ] 연결 NPC와 배틀 프리셋 존재
- [ ] 관장 이벤트의 지급 배지와 리그 배지 일치
- [ ] 사천왕·챔피언에 불필요한 배지 설정 없음
