# 03. 배틀 프리셋

배틀 프리셋은 NPC와 분리된 재사용 가능한 전투 정의입니다. 포켓몬 팀, AI, 규칙, 특수 기믹과 전투 가방을 한곳에서 관리합니다.

[사진: 배틀 프리셋 탭 전체 화면. 목록, 기본 설정, 가방, 포켓몬 팀 영역 표시]

## 새 프리셋 만들기

1. 왼쪽 `＋`를 누릅니다.
2. 파일 ID, 이름, 세대 디렉터리를 입력합니다.
3. 빈 프리셋 또는 `예비 엔트리에서 가져오기`로 시작합니다.
4. 기본 규칙과 팀을 편집합니다.
5. `검증 후 저장`을 누릅니다.

예비 엔트리는 팀·AI·규칙·가방을 복사하므로 기존 트레이너를 빠르게 이식할 때 유용합니다.

## 기본 설정

- 프리셋 이름: 관리 화면에서 알아보기 쉬운 이름
- RCT 트레이너 ID: 게임용 RCT 엔트리 연결
- 배틀 BGM: 비우면 음악 설정의 일반 배틀 기본값 사용
- 포맷·전투 방식: 9세대 싱글 또는 더블을 서로 일치시킴
- AI 난이도: 초보, 일반, 상급, 전문가 계열, 치터
- AI 전략: 균형, 공격, 방어, 에이스 견제, 랭크업, 장판 등
- 레벨 방식: 고정, 플레이어에 맞춤, 플레이어 상한
- 특수 기믹: 메가진화, Z기술, 다이맥스, 테라스탈 허용 여부

## 전투 가방

`아이템 추가`로 회복·상태회복·능력치 아이템과 보유 수량을 설정합니다. `전투당 최대 사용 횟수`를 비우면 별도 제한을 두지 않습니다. 강한 회복 아이템을 여러 개 넣을 때는 난이도 체감이 크게 달라지므로 실제 전투로 확인하세요.

## 포켓몬 팀 편집

팀은 최대 6마리입니다.

1. `포켓몬 추가`를 누릅니다.
2. 종과 폼, 레벨, 성격, 특성, 지닌 도구를 선택합니다.
3. 기술을 구성합니다.
4. IV와 EV를 입력합니다.
5. 슬롯을 좌우로 이동해 출전 순서를 정합니다.

[사진: 포켓몬 한 슬롯의 집중 편집 화면. 종·폼, 특성, 기술, IV/EV 표시]

IV는 능력치별 0~31, EV는 능력치별 0~252이며 총합 510을 넘지 않도록 입력 시 자동 보정됩니다. 지역 폼과 특수 형태는 폼 선택 또는 Cobblemon `aspects` 직접 입력으로 지정할 수 있습니다.

### 팀 재사용

- `참고 엔트리 불러오기`: 기존 참고 팀을 현재 프리셋으로 가져옵니다.
- `엔트리 JSON 복사`: 현재 팀을 클립보드에 복사합니다.
- `엔트리 JSON 붙여넣기`: 다른 프리셋이나 Web Lab에서 가져온 팀을 적용합니다.

붙여넣기 후에는 종, 기술, 특성, 폼과 총 EV를 다시 검증하세요.
