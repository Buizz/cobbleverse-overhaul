# 02. NPC

NPC 탭에서는 한 인물의 이름·외형·행동, 조우 방식, 전투 설정, 보상과 이벤트 스크립트를 편집합니다. 포켓몬 팀 자체는 [배틀 프리셋](03-battle-presets.md)에서 먼저 만드는 편이 좋습니다.

[사진: NPC 탭 전체 화면. 왼쪽 NPC 목록과 오른쪽 기본 정보·외형·행동 영역 표시]

## 새 NPC 만들기

1. 왼쪽 `＋`를 누릅니다.
2. 파일 ID를 소문자·숫자·밑줄로 입력합니다. 예: `route_01_youngster`.
3. 한국어 이름과 세대 디렉터리를 입력합니다.
4. 생성 후 오른쪽 폼의 나머지 값을 채웁니다.
5. `검증 후 저장`을 누릅니다.

ID는 다른 문서가 참조하므로 생성 전에 이름 규칙을 정하세요.

## 기본 정보와 외형

- 한국어·영문 이름: 게임 표시와 관리 검색에 사용합니다.
- 태그: 분류·검색·자동화에 사용할 값을 쉼표로 구분합니다.
- 역할: 일반 NPC 또는 월드 관문에 연결할 관문지키미를 고릅니다.
- 트레이너 클래스: 본가식 직업·분류의 기본값입니다.
- 조직·네임드·리그 인물: 로스터의 기존 인물을 선택합니다.
- 외형 출처: 직접 제작, RCT 개별 스킨, RCT 그룹 스킨 중 선택합니다.
- 스킨·모델 리소스: 실제 외형 리소스 ID입니다. 미리보기로 결과를 확인합니다.

[사진: NPC 외형 미리보기와 트레이너 클래스/스킨 선택 영역]

## 행동과 조우

- 이동 방식: 고정, 제한 배회, 순찰
- 상호작용 거리: 말을 걸 수 있는 범위
- 조우 방식: 직접 상호작용 또는 범위 진입 자동 시작
- 자동 조우 거리와 경고 범위: 접근 이벤트의 단계별 거리
- 플레이어 바라보기, 피해 면역: NPC의 기본 행동 옵션

EasyNPC 기본 거리 단위와 정확히 일치하지 않는 범위는 데이터에 보존되고 전용 런타임 어댑터가 처리합니다.

## 더블배틀 NPC

2인 더블배틀을 사용하려면 두 NPC를 모두 만든 뒤 다음을 설정합니다.

1. 대표 NPC에서 `이 NPC와 파트너를 하나의 공유 조우로 사용`을 켭니다.
2. 파트너 NPC를 선택합니다.
3. 공유 그룹 ID와 클리어 ID를 입력합니다.
4. 더블 형식의 배틀 프리셋을 이벤트에서 연결합니다.
5. 생성된 EasyNPC 소환 명령어를 복사해 테스트합니다.

두 NPC는 이름과 외형은 따로 유지하지만 조우·전투·클리어 상태를 공유합니다.

## 전투와 보상

NPC 탭의 전투 설정은 포맷, 난이도, AI 전략, 레벨 방식과 특수 기믹 허용 여부를 정의합니다. 실제 팀과 전투 가방은 연결된 배틀 프리셋에서 관리합니다.

승리 상금은 고정 금액 또는 지역 평균 레벨 기반으로 정할 수 있습니다. 조건 플래그와 부적금화 같은 배율 아이템 적용 여부도 함께 확인하세요.

기본 상품은 고정 아이템 또는 루트 테이블 중 하나를 사용합니다. 아이템 ID는 가능하면 [게임 데이터](11-game-data.md)에 먼저 선언합니다.

## 이벤트 스크립트

이벤트는 위에서 아래로 실행됩니다. 빠른 프리셋으로 시작한 뒤 필요한 부분만 조정하는 방법이 가장 쉽습니다.

### 빠른 프리셋

- 단순 대화
- 첫 대화 후 다른 대사
- 첫 대화에서 아이템 지급
- 일반 배틀 도전
- 체육관 관장
- 사천왕
- 챔피언

[사진: 빠른 스크립트 프리셋 선택과 적용 버튼]

프리셋의 `적용`은 현재 명령 목록을 교체하므로 기존 스크립트가 있다면 먼저 내용을 확인하세요.

### 사용할 수 있는 명령

대화, 선택지, 조건 분기, 라벨, 라벨 이동, 배틀 시작, 플래그 변경, 클리어 처리, 돈 차감, 아이템·루트 지급, 필드 기술 획득, 이벤트 종료를 조합할 수 있습니다.

분기가 있다면 모든 이동 대상 라벨이 존재하는지, 배틀 시작 명령이 실제 배틀 프리셋을 가리키는지 확인합니다.

## 저장 전 체크리스트

- [ ] 외형 미리보기가 의도한 인물인지 확인
- [ ] 자동 조우 거리보다 경고 종료 거리가 적절히 큰지 확인
- [ ] 싱글/더블 설정과 배틀 프리셋 형식 일치
- [ ] 승리·패배 양쪽 흐름에 종료 또는 유효한 이동 대상 존재
- [ ] 지급 아이템, 플래그, 변수와 배틀 ID가 실제로 존재
- [ ] `검증 후 저장` 성공

고급 JSON 편집은 폼에 없는 전체 데이터를 수정할 때만 사용합니다. `JSON을 편집 폼에 반영`한 후 검증에 성공해야 파일에 저장됩니다.
