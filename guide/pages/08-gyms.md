# 08. 체육관 관리

체육관 관리에서는 속성별 체육관의 공용 외관, BGM, 관장과 기타 트레이너, 내부 방 모듈을 구성합니다.

[사진: 체육관 관리 전체 화면. 기본 설정, 스태프, 평면 배치, 내부 모듈 표시]

## 기본 설정

1. 왼쪽 `＋`로 체육관을 추가하거나 기존 체육관을 선택합니다.
2. 한국어·영문 이름과 18개 속성 타입 중 하나를 고릅니다.
3. 배틀 BGM을 선택합니다. 비워 두면 음악 설정의 체육관 기본값을 사용합니다.
4. 공용 외관 템플릿 NBT를 선택합니다.
5. 실제 사용할 체육관이면 `이 체육관 사용`을 켭니다.

모든 체육관은 공용 `base_gym` 외관을 사용하고 속성에 따라 지정 색상 블록이 치환되는 구조입니다. `NBT 외관 미리보기`로 타입 색상이 의도대로 보이는지 확인하세요.

## 관장과 기타 트레이너

내부 NBT의 NPC 라벨마다 NPC를 배정합니다. 관장은 한 명만 지정하고, 기타 트레이너는 `기타 트레이너 추가`로 필요한 만큼 넣습니다. NPC와 연결 배틀은 먼저 [NPC 탭](02-npc.md)에서 완성하세요.

## 공간 배치

체육관 공간 배치에는 각 방 NBT의 실제 크기, 입구, 관장과 트레이너 위치가 평면도로 표시됩니다.

- 방 드래그: X/Z 좌표 변경
- `전체 보기`: 모든 방이 보이도록 화면 조정
- 범례: 입구, 일반 트레이너, 관장, 내부 모듈 구분

[사진: 여러 내부 모듈과 NPC 마커가 보이는 체육관 평면도]

방을 옮긴 뒤 출입구가 맞닿는지, 모듈이 겹치지 않는지, NPC가 벽 안에 들어가지 않는지 확인합니다.

## 확장형 내부 공간

`내부 모듈 추가`로 방 NBT와 좌표를 연결합니다. 모듈 수와 층수에는 고정 제한이 없지만, 지나치게 큰 조합은 로딩과 동선에 영향을 줄 수 있으므로 필요한 공간만 사용하세요. 공용 내부공간은 [NBT 건물 설정](09-nbt-buildings.md)에서 먼저 만들 수 있습니다.
