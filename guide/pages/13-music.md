# 13. 음악 설정

음악 설정에서는 개별 항목에 BGM이 지정되지 않았을 때 사용할 상황별 기본 곡을 정하고, `음원 태그 → 실제 OGG 경로` 매핑을 관리합니다.

[사진: 음악 설정 화면. 상황별 기본 음악과 활성 트랙 목록 표시]

## 기본 음악

- 일반 타일 기본 BGM
- 도로 기본 BGM
- 마을 기본 BGM
- 동굴·숲 기본 BGM
- 일반 건물·포켓몬센터·포켓몬상점 내부 BGM
- 남성·여성·악역 트레이너 조우 BGM
- 일반 배틀 기본 BGM
- 체육관 배틀 기본 BGM
- 야생·일반 트레이너·체육관 관장 승리 BGM

선택 후 `음원 설정 저장`을 누릅니다. 개별 월드·배틀·체육관에 곡이 지정돼 있으면 개별 설정이 우선하고, 비어 있을 때 기본값이 사용됩니다.

## 음원 태그와 실제 경로

월드·마을·도로·동굴·숲·건물·배틀·체육관 등 모든 사용처에는 OGG 경로가 아니라 `kanto.route_01` 같은 안정적인 음원 태그만 저장됩니다. 실제 파일은 음악 설정의 `음원 태그 매핑`에서 한 번만 연결합니다.

파일을 교체할 때는 변경할 태그와 새 OGG 경로를 선택하고 `태그에 경로 연결`을 누른 뒤 `음원 설정 저장`을 누릅니다. 이미 다른 태그가 쓰는 경로를 선택하면 두 태그의 실제 경로가 서로 교환됩니다.

로컬 OGG 파일이 없어도 태그와 사용처 설정은 삭제되지 않습니다. 따라서 프로젝트를 음원 없이 전달해도 설정을 유지할 수 있으며, 받은 사람이 같은 태그에 자신의 로컬 OGG 경로를 다시 연결할 수 있습니다.

## 사용 가능한 음악

`local-assets/music` 아래 카탈로그에 지정된 폴더에 OGG 파일을 넣고 음악 화면을 열면 자동으로 트랙이 등록됩니다. 화면을 이미 열어 둔 상태라면 `로컬 음원 다시 읽기`를 누릅니다. MIDI 파일은 마인크래프트 리소스팩에서 직접 재생할 수 없으므로 자동 등록하지 않습니다.

자동 등록된 곡은 바로 모든 음원 선택지와 태그 매핑 목록에 나타납니다. 파일명을 기준으로 충돌하지 않는 안정적인 태그가 자동 생성됩니다. 선택지에는 `[태그] 실제 경로`가 함께 표시되지만 저장되는 값은 태그뿐입니다.

새 로컬 음원을 등록한 뒤 실제 게임용 리소스팩을 만들려면 터미널에서 다음을 실행합니다.

```bat
build.bat music
```

또는 전체 `build.bat pack` 과정에서 음악 팩 생성을 함께 수행합니다. 리소스팩에는 폴더나 카탈로그의 모든 곡이 아니라, 상황별 기본값 및 월드·마을·도로·배틀·체육관에 실제 배정된 곡만 포함됩니다.
