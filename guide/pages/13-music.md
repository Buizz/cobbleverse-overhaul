# 13. 음악 설정

음악 설정에서는 개별 항목에 BGM이 지정되지 않았을 때 사용할 상황별 기본 곡을 정하고, `음원 태그 → 실제 OGG 경로` 매핑을 관리합니다.

[사진: 음악 설정 화면. 상황별 기본 음악과 활성 트랙 목록 표시]

## 기본 음악

- 일반 타일 기본 BGM
- 도로 기본 BGM
- 마을 기본 BGM
- 동굴·숲 기본 BGM
- 일반 건물·포켓몬센터·포켓몬상점 내부 BGM
- 남성·여성·악역 트레이너 조우 BGM
- 일반 아이템·중요 아이템·기술머신 획득 효과음
- 일반 배틀 기본 BGM
- 체육관 배틀 기본 BGM
- 야생·일반 트레이너·체육관 관장 승리 BGM

선택 후 `음원 설정 저장`을 누릅니다. 개별 월드·배틀·체육관에 곡이 지정돼 있으면 개별 설정이 우선하고, 비어 있을 때 기본값이 사용됩니다.

건물 문으로 출입할 때뿐 아니라 시작 위치, 이벤트 이동, 재접속으로 건물 내부 차원에 직접 배치될 때도 현재 내부를 다시 판별해 음악을 적용합니다. 체육관 내부는 건물 설정의 전용 태그를 사용하고, 일반 건물은 개별 설정이 없으면 일반 건물 기본 BGM을 사용합니다. 외부·동굴·숲으로 이동하면 내부 음악 상태를 해제한 뒤 해당 지역 BGM으로 복귀합니다.

NPC나 이벤트가 `cobbleventurebag acquire`로 아이템을 지급하면 아이템 종류를 판별해 일반 아이템·중요 아이템·기술머신 효과음 중 하나를 재생합니다. 재생 코드는 음원 경로를 직접 사용하지 않고 각 기본 설정의 태그를 실제 사운드 이벤트로 해석합니다.

## 음원 태그와 실제 경로

월드·마을·도로·동굴·숲·건물·배틀·체육관 등 모든 사용처에는 OGG 경로가 아니라 `kanto.route_01` 같은 안정적인 음원 태그만 저장됩니다. 태그는 실제 사용할 곡에만 만들고 실제 파일은 음악 설정의 `사용할 음원 태그`에서 한 번만 연결합니다.

새 곡을 사용할 때는 `태그 이름`과 OGG 경로를 선택해 `태그 추가·수정`을 누른 뒤 `음원 설정 저장`을 누릅니다. 파일을 교체할 때는 기존 태그 행을 누르고 새 경로를 연결합니다. 같은 경로를 여러 의미로 중복 등록하지 않고 기존 태그를 여러 사용처에서 선택합니다.

로컬 OGG 파일이 없어도 태그와 사용처 설정은 삭제되지 않습니다. 따라서 프로젝트를 음원 없이 전달해도 설정을 유지할 수 있으며, 받은 사람이 같은 태그에 자신의 로컬 OGG 경로를 다시 연결할 수 있습니다.

## 사용 가능한 음악

`local-assets/music` 아래 카탈로그에 지정된 폴더에 OGG 파일을 넣고 음악 화면을 열면 전체 음원 후보 목록에 나타납니다. 화면을 이미 열어 둔 상태라면 `로컬 음원 다시 읽기`를 누릅니다. 이 단계에서는 태그가 생기지 않습니다. MIDI 파일은 마인크래프트 리소스팩에서 직접 재생할 수 없으므로 후보에 포함하지 않습니다.

실제 사용할 곡은 `사용할 음원 태그`에서 의미 있는 태그와 실제 경로를 직접 연결합니다. 예를 들어 `Victory : another-red-bgm/Battle victory trainer.ogg`처럼 등록합니다. 등록한 태그만 모든 음원 선택지에 나타나며 사용처에는 실제 경로가 아니라 태그만 저장됩니다. 폴더의 미사용 음원에는 태그가 생성되지 않습니다.

새 로컬 음원을 등록한 뒤 실제 게임용 리소스팩을 만들려면 터미널에서 다음을 실행합니다.

```bat
build.bat music
```

또는 전체 `build.bat pack` 과정에서 음악 팩 생성을 함께 수행합니다. 리소스팩에는 폴더나 카탈로그의 모든 곡이 아니라, 상황별 기본값 및 월드·마을·도로·배틀·체육관에 실제 배정된 곡만 포함됩니다.
