# 13. 음악 설정

음악 설정에서는 개별 항목에 BGM이 지정되지 않았을 때 사용할 상황별 기본 곡을 정하고, 현재 활성 음악 목록을 확인합니다.

[사진: 음악 설정 화면. 상황별 기본 음악과 활성 트랙 목록 표시]

## 기본 음악

- 일반 타일 기본 BGM
- 도로 기본 BGM
- 마을 기본 BGM
- 일반 배틀 기본 BGM
- 체육관 배틀 기본 BGM

선택 후 `음악 기본값 저장`을 누릅니다. 개별 월드·배틀·체육관에 곡이 지정돼 있으면 개별 설정이 우선하고, 비어 있을 때 기본값이 사용됩니다.

## 사용 가능한 음악

`local-assets/music` 아래 카탈로그에 지정된 폴더에 OGG 파일을 넣고 음악 화면을 열면 자동으로 트랙이 등록됩니다. 화면을 이미 열어 둔 상태라면 `로컬 음원 다시 읽기`를 누릅니다. MIDI 파일은 마인크래프트 리소스팩에서 직접 재생할 수 없으므로 자동 등록하지 않습니다.

자동 등록된 곡은 바로 월드·배틀·체육관의 선택지에 나타납니다. 파일명을 기준으로 표시 이름과 충돌하지 않는 내부 ID가 자동 생성됩니다.

새 로컬 음원을 등록한 뒤 실제 게임용 리소스팩을 만들려면 터미널에서 다음을 실행합니다.

```bat
build.bat music
```

또는 전체 `build.bat pack` 과정에서 음악 팩 생성을 함께 수행합니다. 리소스팩에는 폴더나 카탈로그의 모든 곡이 아니라, 상황별 기본값 및 월드·마을·도로·배틀·체육관에 실제 배정된 곡만 포함됩니다.
